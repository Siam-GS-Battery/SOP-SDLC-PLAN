## 🧭 Documentation Policy
- All documents should be **stored under `/documentation/` folder**.
- Each version update must be recorded in a **Change Log** at the end of this README.
- Links (FigJam / Figma / Asana) must be **public viewable** for reviewers.
- File names must follow the format:
  > `<phase>_<document_title>_<version>.<ext>`
  > Example: `1.1_Raw_Requirement_List_v1.0.xlsx`
