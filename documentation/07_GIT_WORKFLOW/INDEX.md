# Phase 7: Git Workflow

> มาตรฐานการใช้ Git และกระบวนการทำงานร่วมกัน

## เอกสารในหมวดนี้

| ลำดับ | เอกสาร | คำอธิบาย |
|:-----:|:-------|:---------|
| 7.1 | [Branching Strategy](7.1_Branching_Strategy.md) | กลยุทธ์การจัดการ Branch |
| 7.2 | [Commit Message Convention](7.2_Commit_Message_Convention.md) | มาตรฐานการเขียน Commit Message |

## ลำดับการอ่านแนะนำ

1. อ่าน **Branching Strategy** เพื่อเข้าใจการจัดการ branches
2. ดู **Commit Message Convention** ก่อนเขียน commit แรก
3. อ่าน **Pull Request Process** เมื่อต้องส่ง PR
4. ดู **Code Review Guidelines** เมื่อต้อง review code ของคนอื่น
