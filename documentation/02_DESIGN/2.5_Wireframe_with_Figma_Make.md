# 2.5 Wireframe with Figma Make (AI)

## Figma Make คืออะไร?

Figma Make เป็นฟีเจอร์ AI ใน Figma ที่ช่วยสร้าง Wireframe และ UI Design จาก text prompt โดยอัตโนมัติ ทำให้การออกแบบเร็วขึ้นมาก

---

## ข้อดีของ Figma Make

| ข้อดี | รายละเอียด |
|-------|------------|
| **เร็วมาก** | สร้าง wireframe ได้ภายในไม่กี่วินาที |
| **ไม่ต้องเริ่มจากศูนย์** | AI สร้าง base design ให้ แล้วค่อยปรับแต่ง |
| **หลากหลาย Variations** | สามารถ generate หลายแบบแล้วเลือกที่ชอบ |
| **เหมาะกับ Brainstorming** | ทดลองไอเดียได้รวดเร็ว |
| **รองรับ Components** | สร้าง design ที่ใช้ Figma components ได้ |

---

## วิธีเปิดใช้งาน Figma Make

### ขั้นตอนที่ 1: เข้าถึง Figma Make

1. เปิด Figma Design file
2. กด **Actions menu** (ไอคอน ⚡ หรือกด `Ctrl/Cmd + /`)
3. พิมพ์ "Make" หรือเลือก **"Make a design"**

หรือ

1. คลิกขวาบน Canvas
2. เลือก **"Make a design"**

### ขั้นตอนที่ 2: เขียน Prompt

เขียน prompt อธิบายสิ่งที่ต้องการ เช่น:

```
Create a login page wireframe with email and password fields,
a login button, and a "forgot password" link. Include a logo
placeholder at the top.
```

### ขั้นตอนที่ 3: Generate และเลือก

1. กด **Generate**
2. รอ AI สร้าง design (ไม่กี่วินาที)
3. ดู preview แล้วเลือก **Insert** หรือ **Generate more** เพื่อดูแบบอื่น

## ตัวอย่าง Prompts สำหรับ Wireframe

### 1. Login / Authentication Pages

```
Create a simple login page wireframe with:
- Logo placeholder at top
- Email input field
- Password input field
- "Remember me" checkbox
- Login button (primary)
- "Forgot password" link
- "Sign up" link at bottom
Mobile-first design, grayscale
```

### 2. Dashboard Page

```
Create a dashboard wireframe with:
- Top navigation bar with logo, search, notifications, profile
- Left sidebar with menu items
- Main content area with 4 stat cards
- A data table below the cards
- Grayscale, clean layout
```

### 3. Form Page

```
Create a user registration form wireframe:
- Header with title "Create Account"
- Fields: First name, Last name, Email, Phone, Password, Confirm password
- Terms and conditions checkbox
- Submit button
- Progress indicator at top (Step 2 of 3)
```

### 4. List/Table View

```
Create a user management table wireframe:
- Page title "Users"
- Search bar and filter buttons
- Add new user button
- Table with columns: Avatar, Name, Email, Role, Status, Actions
- Pagination at bottom
- 10 rows of sample data
```

### 5. Detail/Profile Page

```
Create a user profile page wireframe:
- Cover image placeholder
- Profile avatar (large, circular)
- User name and title
- Edit profile button
- Tabs: Overview, Activity, Settings
- Overview content with bio and contact info
```

### 6. Settings Page

```
Create a settings page wireframe:
- Left sidebar with settings categories
- Main content area
- Form sections with labels and inputs
- Toggle switches for boolean options
- Save and Cancel buttons at bottom
```

### 7. E-commerce Product Page

```
Create a product detail page wireframe:
- Product image gallery (main + thumbnails)
- Product title and price
- Rating stars and review count
- Size/color selectors
- Quantity selector
- Add to cart button
- Product description tabs
```

### 8. Mobile App Screens

```
Create a mobile app home screen wireframe (375px width):
- Bottom navigation with 5 icons
- Top header with hamburger menu and notifications
- Search bar
- Horizontal scrolling category pills
- Vertical list of cards with image, title, description
```

## Tips สำหรับเขียน Prompt ที่ดี

### ✅ DO: Prompt ที่ดี

1. **ระบุ Layout ชัดเจน**
   ```
   Create a two-column layout with sidebar on left (250px)
   and main content on right
   ```

2. **บอก Elements ที่ต้องการ**
   ```
   Include: header, search bar, filter dropdown, data table
   with 5 columns, pagination
   ```

3. **ระบุ Style**
   ```
   Grayscale wireframe style, minimal, clean spacing
   ```

4. **บอกขนาด/Platform**
   ```
   Mobile wireframe, 375px width, iOS style
   ```

5. **อ้างอิง Design ที่รู้จัก**
   ```
   Similar to Notion's page layout
   ```

### ❌ DON'T: Prompt ที่ไม่ดี

1. **คลุมเครือเกินไป**
   ```
   ❌ Make a nice page
   ✅ Create a dashboard with stats cards and a line chart
   ```

2. **ไม่บอก context**
   ```
   ❌ Login form
   ✅ Mobile login form with social login options, 375px width
   ```

3. **ขอมากเกินไปใน prompt เดียว**
   ```
   ❌ Create entire app with 20 screens
   ✅ Create login screen (แล้วค่อยทำทีละหน้า)
   ```

## Workflow แนะนำ

### Step 1: เตรียม UX Flow ก่อน
- ดู UX Flow Diagram จาก [2.1_UX_Flow_Diagram](./2.1_UX_Flow_Diagram_FigJam_Link.md)
- List หน้าจอทั้งหมดที่ต้องสร้าง

### Step 2: สร้าง Wireframe ทีละหน้าด้วย Figma Make
```
UX Flow Screen → Figma Make Prompt → Generate → Adjust
```

### Step 3: ปรับแต่ง Output
- แก้ไข spacing, alignment
- เพิ่ม/ลบ elements ตามต้องการ
- ปรับ typography ให้ consistent

### Step 4: สร้าง Components
- แปลง elements ที่ใช้ซ้ำเป็น Components
- เช่น Button, Input, Card, Navigation

### Step 5: Review และ Iterate
- ตรวจสอบกับ UX Flow ว่าครบทุกหน้า
- ขอ feedback จากทีม
- แก้ไขตาม feedback

## ข้อจำกัดของ Figma Make

| ข้อจำกัด | วิธีแก้ไข |
|----------|----------|
| ผลลัพธ์อาจไม่ตรงใจ 100% | Generate หลายครั้ง แล้วเลือกที่ใกล้เคียงที่สุด |
| ไม่รองรับ prompt ภาษาไทย | ใช้ภาษาอังกฤษในการเขียน prompt |
| Complex layouts อาจผิดพลาด | แบ่ง prompt เป็นส่วนย่อยๆ |
| ต้องปรับแต่งเสมอ | ใช้เป็น starting point แล้วค่อย refine |
| ต้องมี Figma account | สมัคร Figma ฟรี |

---

## เปรียบเทียบ: Manual vs Figma Make

| หัวข้อ | Manual | Figma Make |
|--------|--------|------------|
| **เวลา** | 30-60 นาที/หน้า | 5-10 นาที/หน้า |
| **ความแม่นยำ** | สูง (ควบคุมได้ทั้งหมด) | ปานกลาง (ต้องปรับแต่ง) |
| **Learning Curve** | สูง | ต่ำ |
| **Consistency** | ขึ้นกับ designer | ต้องปรับเอง |
| **เหมาะกับ** | Final design | Rapid prototyping |

**แนะนำ**: ใช้ Figma Make สำหรับ rapid wireframing และ brainstorming แล้วค่อยปรับแต่ง manual
