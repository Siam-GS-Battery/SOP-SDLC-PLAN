## วัฒนธรรมการทำงาน

### Core Values

| ค่านิยม | ความหมาย |
|---------|----------|
| **Ownership** | รับผิดชอบงานของตัวเองอย่างเต็มที่ |
| **Collaboration** | ทำงานร่วมกันเป็นทีม ช่วยเหลือกัน |
| **Continuous Learning** | เรียนรู้สิ่งใหม่ตลอดเวลา |
| **Quality First** | คุณภาพมาก่อนความเร็ว |
| **Transparency** | สื่อสารอย่างเปิดเผยและตรงไปตรงมา |

### การประชุมประจำ

| ประชุม | วัน/เวลา | รูปแบบ | วัตถุประสงค์ |
|--------|----------|--------|--------------|
| **StandUp Meeting** | ทุกวัน 08:45 น. | 15 นาที | อัปเดตงาน |
| **IT Meeting** | ทุกต้นเดือน | 1-3 ชม. | อัปเดตงาน |
| **DM Weekly Meeting** | ทุกวันพฤ | 1-2 ชม. | อัปเดตงาน |


### เวลาทำงาน

- **Core Hours**: 7:30 - 16:30 น. (ต้องอยู่ในช่วงนี้)
- **Flexible Hours**: สามารถยืดหยุ่นได้นอก Core Hours
- **Work From Home**: [ระบุนโยบาย WFH]

### กฎของทีม

1. **ตรงต่อเวลา** - เข้าประชุมตรงเวลาเสมอ
2. **Update Status** - อัปเดตความคืบหน้าบน Asana ทุกวัน
3. **Ask for Help** - ไม่แน่ใจให้ถาม อย่าเก็บไว้คนเดียว
4. **Code Review** - ทุก PR ต้องผ่านการ Review ก่อน Merge
5. **Document** - เขียน Document สำหรับงานสำคัญ

## คำถามที่พบบ่อย

### Q: ถ้ามีคำถามเกี่ยวกับงานควรถามใคร?
**A:** ถาม Buddy ก่อน หรือโพสต์ใน Channel `#dev-team` ทีมจะช่วยตอบ

### Q: ต้องการเข้าถึง Repository ทำอย่างไร?
**A:** ดูเอกสาร [0.3_Access_Request_Checklist.md](0.3_Access_Request_Checklist.md) และขอ Access จาก Tech Lead

### Q: ถ้าไม่เข้าใจ Requirement ควรทำอย่างไร?
**A:** ถาม PM หรือ Tech Lead ก่อนเริ่มงานเสมอ การถามคำถามคือสิ่งที่ดี

### Q: Code Review ใช้เวลานานแค่ไหน?
**A:** ปกติ 1-2 วันทำการ ถ้าด่วนให้แจ้งใน Channel `#code-review`

### Q: ถ้าทำผิดพลาดควรทำอย่างไร?
**A:** แจ้งทีมทันที อย่าปิดบัง เราเรียนรู้จากความผิดพลาด
