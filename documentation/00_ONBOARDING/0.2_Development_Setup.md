## Essential Tools

### 1. Git

Version control สำหรับจัดการ Source Code

#### Windows
```powershell
# ดาวน์โหลดจาก https://git-scm.com/download/win
# หรือใช้ winget
winget install Git.Git
```

#### macOS
```bash
# ใช้ Homebrew
brew install git
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install git
```

#### ตั้งค่า Git Config
```bash
# ตั้งชื่อและอีเมล (ใช้อีเมลองค์กร)
git config --global user.name "ชื่อ นามสกุล"
git config --global user.email "your.email@company.com"

# ตั้งค่า Default Branch
git config --global init.defaultBranch main

# ตั้งค่า Editor
git config --global core.editor "code --wait"

# ตรวจสอบการตั้งค่า
git config --list
```

### 2. Node.js

JavaScript Runtime สำหรับ Frontend และ Backend

#### แนะนำ: ใช้ NVM (Node Version Manager)

**Windows** - ใช้ [nvm-windows](https://github.com/coreybutler/nvm-windows)
```powershell
# ดาวน์โหลดและติดตั้งจาก https://github.com/coreybutler/nvm-windows/releases
# หลังติดตั้ง เปิด Terminal ใหม่

nvm install 20
nvm use 20
```

**macOS / Linux**
```bash
# ติดตั้ง NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Restart terminal แล้วรัน
nvm install 20
nvm use 20
nvm alias default 20
```

#### ตรวจสอบการติดตั้ง
```bash
node --version  # ควรได้ v20.x.x
npm --version   # ควรได้ 10.x.x
```

#### ติดตั้ง Global Packages ที่จำเป็น
```bash
npm install -g pnpm          # Package manager ที่เร็วกว่า npm
npm install -g typescript    # TypeScript compiler
npm install -g ts-node       # Run TypeScript directly
```


#### VSCode Settings (settings.json)

กด `Ctrl+Shift+P` (Windows/Linux) หรือ `Cmd+Shift+P` (macOS) แล้วพิมพ์ "Open User Settings (JSON)"

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "editor.tabSize": 2,
  "editor.wordWrap": "on",
  "files.autoSave": "onFocusChange",
  "typescript.preferences.importModuleSpecifier": "relative",
  "emmet.includeLanguages": {
    "javascript": "javascriptreact",
    "typescript": "typescriptreact"
  },
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[json]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  }
}
```

## Development Environment

### Clone โปรเจค

```bash
# สร้างโฟลเดอร์สำหรับเก็บโปรเจค
mkdir ~/Projects
cd ~/Projects

# Clone repository
git clone https://github.com/[organization]/[project-name].git
cd [project-name]

# ติดตั้ง Dependencies
npm install
# หรือ
pnpm install
```

### Environment Variables

```bash
# Copy ไฟล์ .env.example เป็น .env.local
cp .env.example .env.local

# แก้ไขค่าตาม Environment ของคุณ
code .env.local
```

**ตัวอย่าง .env.local:**
```env
# API
NEXT_PUBLIC_API_URL=http://localhost:3001

# Supabase
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

# Others
NODE_ENV=development
```

> ⚠️ **สำคัญ**: ไม่ commit ไฟล์ .env ขึ้น Git เด็ดขาด!

### รัน Development Server

```bash
# Frontend
npm run dev

# Backend (ถ้าแยก)
npm run dev:server

# ทั้งคู่พร้อมกัน (ถ้ามี script)
npm run dev:all
```

## Verification

### Checklist ตรวจสอบการติดตั้ง

รันคำสั่งเหล่านี้เพื่อตรวจสอบว่าติดตั้งครบถ้วน:

```bash
# Git
git --version
# ✓ ควรได้ git version 2.x.x

# Node.js
node --version
# ✓ ควรได้ v20.x.x

# npm
npm --version
# ✓ ควรได้ 10.x.x

# pnpm (ถ้าติดตั้ง)
pnpm --version
# ✓ ควรได้ 8.x.x

# TypeScript
tsc --version
# ✓ ควรได้ Version 5.x.x

# Docker (ถ้าติดตั้ง)
docker --version
# ✓ ควรได้ Docker version 24.x.x
```

### ทดสอบ Clone และ Run โปรเจค

```bash
# Clone โปรเจค
git clone [repository-url]
cd [project-name]

# ติดตั้ง Dependencies
npm install

# รัน Development Server
npm run dev

# เปิด Browser ไปที่ http://localhost:3000
# ✓ ควรเห็นหน้าเว็บแสดงผลได้ปกติ
```

## Troubleshooting

### ปัญหาที่พบบ่อย

#### 1. Node.js version ไม่ตรง
```bash
# ใช้ NVM เปลี่ยน version
nvm install 20
nvm use 20
```

#### 2. Permission denied เวลา npm install
```bash
# macOS/Linux - ห้ามใช้ sudo กับ npm install
# ใช้ NVM แทนการติดตั้ง Node.js แบบ global

# Windows - Run Terminal as Administrator
```

#### 3. Port 3000 ถูกใช้งานอยู่
```bash
# หา Process ที่ใช้ Port
# Windows
netstat -ano | findstr :3000

# macOS/Linux
lsof -i :3000

# Kill Process
# Windows
taskkill /PID [PID] /F

# macOS/Linux
kill -9 [PID]
```

#### 4. Git authentication failed
```bash
# ใช้ SSH Key แทน HTTPS
# สร้าง SSH Key
ssh-keygen -t ed25519 -C "your.email@company.com"

# เพิ่ม SSH Key ไปที่ GitHub
cat ~/.ssh/id_ed25519.pub
# Copy และไปเพิ่มที่ GitHub > Settings > SSH Keys
```
