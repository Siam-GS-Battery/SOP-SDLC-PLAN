# 6.3 Integration Test Guide

> แนวทางการเขียน Integration Test สำหรับ API Endpoints และ Database

---

## วัตถุประสงค์

Integration Test คือการทดสอบ **การทำงานร่วมกัน** ระหว่างหลาย modules เพื่อ:
1. ตรวจสอบว่า API endpoints ทำงานถูกต้อง end-to-end
2. ตรวจสอบว่า database queries ได้ผลลัพธ์ที่ถูกต้อง
3. ตรวจสอบ middleware chain (auth, validation, error handling)
4. ตรวจสอบ data flow ตั้งแต่ request → controller → service → repository → response

---

## ความแตกต่างจาก Unit Test

| | Unit Test | Integration Test |
|:-|:---------|:----------------|
| **Scope** | Function/Component เดียว | หลาย modules ร่วมกัน |
| **Dependencies** | Mock ทั้งหมด | ใช้ของจริง (DB, server) |
| **ความเร็ว** | เร็วมาก (ms) | ปานกลาง (s) |
| **จำนวน** | มาก (70%) | ปานกลาง (20%) |
| **เป้าหมาย** | Logic ถูกไหม? | ทำงานร่วมกันได้ไหม? |

---

## เครื่องมือที่ใช้

| เครื่องมือ | วัตถุประสงค์ | ติดตั้ง |
|:----------|:------------|:--------|
| **Vitest** | Test runner | `npm install -D vitest` |
| **Supertest** | HTTP request testing | `npm install -D supertest @types/supertest` |
| **Supabase** | Test database | ใช้ Supabase project แยกสำหรับ test |

## การตั้งค่า

### 1. แยก App จาก Server

แยก Express app ออกจาก `server.listen()` เพื่อให้ Supertest ใช้ได้:

**`src/app.ts`** (แยก app ออกมา)

```typescript
import express from 'express';
import cors from 'cors';
import { productRoutes } from './routes/product.routes';
import { authRoutes } from './routes/auth.routes';
import { errorHandler } from './middleware/error.handler';

const app = express();

app.use(cors());
app.use(express.json());

app.use('/api/auth', authRoutes);
app.use('/api/products', productRoutes);

app.use(errorHandler);

export default app;
```

**`src/server.ts`** (เฉพาะ production)

```typescript
import app from './app';

const PORT = process.env.PORT || 5001;
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```

### 2. Test Database Setup

**`src/__tests__/setup.ts`**

```typescript
import { beforeAll, afterAll, beforeEach } from 'vitest';
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  process.env.TEST_SUPABASE_URL!,
  process.env.TEST_SUPABASE_SERVICE_KEY!
);

beforeAll(async () => {
  // ตรวจสอบ connection
  const { error } = await supabase.from('products').select('count');
  if (error) throw new Error(`Database connection failed: ${error.message}`);
});

beforeEach(async () => {
  // Reset test data ก่อนทุก test
  await supabase.from('order_items').delete().neq('id', '');
  await supabase.from('orders').delete().neq('id', '');
  await supabase.from('cart_items').delete().neq('id', '');
  await supabase.from('products').delete().neq('id', '');
  await supabase.from('categories').delete().neq('id', '');

  // Seed test data
  await supabase.from('categories').insert([
    { id: 'cat-1', name: 'Electronics' },
    { id: 'cat-2', name: 'Clothing' },
  ]);

  await supabase.from('products').insert([
    { id: 'prod-1', name: 'Laptop', price: 25000, category_id: 'cat-1', status: 'active' },
    { id: 'prod-2', name: 'T-Shirt', price: 350, category_id: 'cat-2', status: 'active' },
  ]);
});

afterAll(async () => {
  // Cleanup
  await supabase.from('order_items').delete().neq('id', '');
  await supabase.from('orders').delete().neq('id', '');
  await supabase.from('cart_items').delete().neq('id', '');
  await supabase.from('products').delete().neq('id', '');
  await supabase.from('categories').delete().neq('id', '');
});
```

## ตัวอย่าง: API Integration Tests

### 1. Test Authentication API

**`src/__tests__/api/auth.api.test.ts`**

```typescript
import { describe, it, expect, beforeEach } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Auth API', () => {
  const testUser = {
    email: 'test@example.com',
    password: 'SecureP@ss123',
    name: 'Test User',
  };

  describe('POST /api/auth/register', () => {
    it('should register a new user and return token', async () => {
      const res = await request(app)
        .post('/api/auth/register')
        .send(testUser);

      expect(res.status).toBe(201);
      expect(res.body).toHaveProperty('token');
      expect(res.body.user).toMatchObject({
        email: testUser.email,
        name: testUser.name,
      });
      expect(res.body.user).not.toHaveProperty('password');
    });

    it('should return 400 when email is invalid', async () => {
      const res = await request(app)
        .post('/api/auth/register')
        .send({ ...testUser, email: 'invalid-email' });

      expect(res.status).toBe(400);
      expect(res.body).toHaveProperty('error');
    });

    it('should return 409 when email already exists', async () => {
      // Register first time
      await request(app).post('/api/auth/register').send(testUser);

      // Register again with same email
      const res = await request(app)
        .post('/api/auth/register')
        .send(testUser);

      expect(res.status).toBe(409);
    });
  });

  describe('POST /api/auth/login', () => {
    beforeEach(async () => {
      await request(app).post('/api/auth/register').send(testUser);
    });

    it('should login and return token', async () => {
      const res = await request(app)
        .post('/api/auth/login')
        .send({ email: testUser.email, password: testUser.password });

      expect(res.status).toBe(200);
      expect(res.body).toHaveProperty('token');
    });

    it('should return 401 with wrong password', async () => {
      const res = await request(app)
        .post('/api/auth/login')
        .send({ email: testUser.email, password: 'wrong-password' });

      expect(res.status).toBe(401);
    });

    it('should return 401 with non-existent email', async () => {
      const res = await request(app)
        .post('/api/auth/login')
        .send({ email: 'nobody@example.com', password: 'password' });

      expect(res.status).toBe(401);
    });
  });
});
```

### 2. Test Products API (CRUD)

**`src/__tests__/api/products.api.test.ts`**

```typescript
import { describe, it, expect, beforeEach } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Products API', () => {
  let authToken: string;

  beforeEach(async () => {
    // Register and login to get token
    await request(app)
      .post('/api/auth/register')
      .send({ email: 'admin@test.com', password: 'Admin123!', name: 'Admin' });

    const loginRes = await request(app)
      .post('/api/auth/login')
      .send({ email: 'admin@test.com', password: 'Admin123!' });

    authToken = loginRes.body.token;
  });

  describe('GET /api/products', () => {
    it('should return list of products', async () => {
      const res = await request(app).get('/api/products');

      expect(res.status).toBe(200);
      expect(res.body.data).toBeInstanceOf(Array);
      expect(res.body.data.length).toBeGreaterThanOrEqual(2);
    });

    it('should support pagination', async () => {
      const res = await request(app)
        .get('/api/products')
        .query({ page: 1, limit: 1 });

      expect(res.status).toBe(200);
      expect(res.body.data).toHaveLength(1);
      expect(res.body.pagination).toMatchObject({
        page: 1,
        limit: 1,
        total: expect.any(Number),
      });
    });

    it('should filter by category', async () => {
      const res = await request(app)
        .get('/api/products')
        .query({ category_id: 'cat-1' });

      expect(res.status).toBe(200);
      expect(res.body.data.every((p: any) => p.category_id === 'cat-1')).toBe(true);
    });
  });

  describe('GET /api/products/:id', () => {
    it('should return product by id', async () => {
      const res = await request(app).get('/api/products/prod-1');

      expect(res.status).toBe(200);
      expect(res.body.data).toMatchObject({
        id: 'prod-1',
        name: 'Laptop',
        price: 25000,
      });
    });

    it('should return 404 for non-existent product', async () => {
      const res = await request(app).get('/api/products/non-existent');

      expect(res.status).toBe(404);
    });
  });

  describe('POST /api/products', () => {
    it('should create a new product when authenticated', async () => {
      const newProduct = {
        name: 'New Product',
        price: 999,
        category_id: 'cat-1',
      };

      const res = await request(app)
        .post('/api/products')
        .set('Authorization', `Bearer ${authToken}`)
        .send(newProduct);

      expect(res.status).toBe(201);
      expect(res.body.data).toMatchObject(newProduct);
      expect(res.body.data).toHaveProperty('id');
    });

    it('should return 401 without authentication', async () => {
      const res = await request(app)
        .post('/api/products')
        .send({ name: 'Test', price: 100, category_id: 'cat-1' });

      expect(res.status).toBe(401);
    });

    it('should return 400 with invalid data', async () => {
      const res = await request(app)
        .post('/api/products')
        .set('Authorization', `Bearer ${authToken}`)
        .send({ name: '', price: -1 });

      expect(res.status).toBe(400);
    });
  });

  describe('PUT /api/products/:id', () => {
    it('should update existing product', async () => {
      const res = await request(app)
        .put('/api/products/prod-1')
        .set('Authorization', `Bearer ${authToken}`)
        .send({ name: 'Updated Laptop', price: 27000 });

      expect(res.status).toBe(200);
      expect(res.body.data.name).toBe('Updated Laptop');
      expect(res.body.data.price).toBe(27000);
    });

    it('should return 404 for non-existent product', async () => {
      const res = await request(app)
        .put('/api/products/non-existent')
        .set('Authorization', `Bearer ${authToken}`)
        .send({ name: 'Test' });

      expect(res.status).toBe(404);
    });
  });

  describe('DELETE /api/products/:id', () => {
    it('should delete product', async () => {
      const res = await request(app)
        .delete('/api/products/prod-1')
        .set('Authorization', `Bearer ${authToken}`);

      expect(res.status).toBe(200);

      // Verify deleted
      const getRes = await request(app).get('/api/products/prod-1');
      expect(getRes.status).toBe(404);
    });
  });
});
```

### 3. Test Middleware Chain

**`src/__tests__/api/middleware.api.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Middleware', () => {
  describe('Authentication Middleware', () => {
    it('should reject requests without token', async () => {
      const res = await request(app).post('/api/products').send({});

      expect(res.status).toBe(401);
      expect(res.body.error).toMatch(/token/i);
    });

    it('should reject invalid token', async () => {
      const res = await request(app)
        .post('/api/products')
        .set('Authorization', 'Bearer invalid-token')
        .send({});

      expect(res.status).toBe(401);
    });

    it('should reject expired token', async () => {
      // Use a known expired token for testing
      const expiredToken = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOiIxIiwiZXhwIjoxMDAwMDAwMDAwfQ.invalid';

      const res = await request(app)
        .post('/api/products')
        .set('Authorization', `Bearer ${expiredToken}`)
        .send({});

      expect(res.status).toBe(401);
    });
  });

  describe('Validation Middleware', () => {
    let authToken: string;

    beforeAll(async () => {
      await request(app)
        .post('/api/auth/register')
        .send({ email: 'validator@test.com', password: 'Test123!', name: 'Tester' });

      const res = await request(app)
        .post('/api/auth/login')
        .send({ email: 'validator@test.com', password: 'Test123!' });

      authToken = res.body.token;
    });

    it('should return 400 with validation error details', async () => {
      const res = await request(app)
        .post('/api/products')
        .set('Authorization', `Bearer ${authToken}`)
        .send({ name: '', price: 'not-a-number' });

      expect(res.status).toBe(400);
      expect(res.body.errors).toBeInstanceOf(Array);
      expect(res.body.errors.length).toBeGreaterThan(0);
    });
  });

  describe('Error Handler', () => {
    it('should return 404 for unknown routes', async () => {
      const res = await request(app).get('/api/unknown-endpoint');

      expect(res.status).toBe(404);
    });

    it('should return JSON error format', async () => {
      const res = await request(app).get('/api/unknown-endpoint');

      expect(res.body).toHaveProperty('error');
      expect(res.headers['content-type']).toMatch(/json/);
    });
  });
});
```

## Checklist สำหรับ API Test Coverage

ทุก API endpoint ต้องมี test อย่างน้อยตาม matrix นี้:

| Endpoint | Happy Path | Bad Input (400) | Unauthorized (401) | Not Found (404) | Conflict (409) |
|:---------|:----------:|:---------------:|:------------------:|:---------------:|:--------------:|
| POST /auth/register | ✅ | ✅ | - | - | ✅ |
| POST /auth/login | ✅ | ✅ | ✅ | - | - |
| GET /products | ✅ | - | - | - | - |
| GET /products/:id | ✅ | - | - | ✅ | - |
| POST /products | ✅ | ✅ | ✅ | - | - |
| PUT /products/:id | ✅ | ✅ | ✅ | ✅ | - |
| DELETE /products/:id | ✅ | - | ✅ | ✅ | - |

## Best Practices

### DO's
- **แยก test database** จาก development database
- **Reset data** ก่อนทุก test (ใช้ `beforeEach`)
- Test ทั้ง **success** และ **error** cases
- ตรวจสอบ **response body structure** ไม่ใช่แค่ status code
- ตรวจสอบ **side effects** (เช่น สร้าง product แล้ว GET เจอจริงไหม)

### DON'Ts
- อย่าใช้ **production database** สำหรับ test
- อย่าพึ่งพา **ข้อมูลจาก test อื่น** (ต้อง independent)
- อย่า **hardcode** token — สร้างใหม่ใน beforeEach
- อย่า test **third-party service** (mock ถ้าจำเป็น)
- อย่าลืม **cleanup** หลัง test suite จบ
