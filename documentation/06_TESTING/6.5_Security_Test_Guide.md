# 6.5 Security Test Guide

> แนวทางการทดสอบความปลอดภัยตาม OWASP Top 10

---

## วัตถุประสงค์

Security Test คือการทดสอบว่าระบบ **ปลอดภัยจากช่องโหว่ที่พบบ่อย** เพื่อ:
1. ป้องกันข้อมูลผู้ใช้ถูกเข้าถึงโดยไม่ได้รับอนุญาต
2. ป้องกันการโจมตีที่พบบ่อย (SQL Injection, XSS, CSRF)
3. ตรวจสอบ Authentication และ Authorization ทำงานถูกต้อง
4. ให้เป็นไปตามมาตรฐาน OWASP Top 10

---

## OWASP Top 10 — สิ่งที่ต้องทดสอบ

| อันดับ | ช่องโหว่ | ความรุนแรง | เกี่ยวข้องกับโปรเจคเรา |
|:------:|:---------|:----------:|:----------------------:|
| A01 | Broken Access Control | สูงมาก | ✅ |
| A02 | Cryptographic Failures | สูง | ✅ |
| A03 | Injection (SQL, NoSQL, XSS) | สูง | ✅ |
| A04 | Insecure Design | ปานกลาง | ✅ |
| A05 | Security Misconfiguration | ปานกลาง | ✅ |
| A06 | Vulnerable Components | ปานกลาง | ✅ |
| A07 | Authentication Failures | สูง | ✅ |
| A08 | Software & Data Integrity | ปานกลาง | ⚠️ |
| A09 | Security Logging & Monitoring | ต่ำ | ✅ |
| A10 | Server-Side Request Forgery | ต่ำ | ⚠️ |

## 1. Dependency Vulnerability Scanning

### npm audit

```bash
# ตรวจสอบ vulnerabilities
npm audit

# ดูเฉพาะ high และ critical
npm audit --audit-level=high

# แก้ไขอัตโนมัติ
npm audit fix

# ดู report แบบ JSON
npm audit --json
```

### ตั้งค่าใน CI/CD

```yaml
# GitHub Actions example
- name: Security Audit
  run: npm audit --audit-level=high
```

### ESLint Security Plugin

```bash
npm install -D eslint-plugin-security
```

**`.eslintrc.js`** (เพิ่ม)

```javascript
module.exports = {
  plugins: ['security'],
  extends: ['plugin:security/recommended-legacy'],
};
```

Plugin นี้จะตรวจจับ:
- `eval()` usage
- Non-literal `require()`
- Regex DoS patterns
- Unsafe object property access
- Hardcoded credentials

## 2. Authentication & Authorization Tests

### Test Cases สำหรับ Authentication

**`src/__tests__/security/auth.security.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Authentication Security', () => {
  // =====================
  // A07: Authentication Failures
  // =====================

  describe('Brute Force Protection', () => {
    it('should rate limit after multiple failed login attempts', async () => {
      const attempts = [];
      for (let i = 0; i < 10; i++) {
        attempts.push(
          request(app)
            .post('/api/auth/login')
            .send({ email: 'user@test.com', password: `wrong-${i}` })
        );
      }

      const responses = await Promise.all(attempts);
      const rateLimited = responses.some((r) => r.status === 429);

      expect(rateLimited).toBe(true);
    });
  });

  describe('Password Security', () => {
    it('should reject weak passwords', async () => {
      const weakPasswords = ['123456', 'password', 'abc', '12345678'];

      for (const password of weakPasswords) {
        const res = await request(app)
          .post('/api/auth/register')
          .send({ email: 'test@test.com', password, name: 'Test' });

        expect(res.status).toBe(400);
      }
    });

    it('should not return password in response', async () => {
      await request(app)
        .post('/api/auth/register')
        .send({ email: 'nopass@test.com', password: 'Secure@123', name: 'Test' });

      const res = await request(app)
        .post('/api/auth/login')
        .send({ email: 'nopass@test.com', password: 'Secure@123' });

      expect(res.body.user).not.toHaveProperty('password');
      expect(res.body.user).not.toHaveProperty('password_hash');
      expect(JSON.stringify(res.body)).not.toMatch(/password/i);
    });
  });

  describe('JWT Security', () => {
    it('should reject tampered tokens', async () => {
      // Register and login
      await request(app)
        .post('/api/auth/register')
        .send({ email: 'jwt@test.com', password: 'Secure@123', name: 'JWT' });

      const loginRes = await request(app)
        .post('/api/auth/login')
        .send({ email: 'jwt@test.com', password: 'Secure@123' });

      const token = loginRes.body.token;
      const tamperedToken = token.slice(0, -5) + 'XXXXX'; // tamper signature

      const res = await request(app)
        .get('/api/products')
        .set('Authorization', `Bearer ${tamperedToken}`);

      expect(res.status).toBe(401);
    });

    it('should reject tokens signed with different secret', async () => {
      const jwt = await import('jsonwebtoken');
      const fakeToken = jwt.default.sign(
        { userId: '1', role: 'admin' },
        'different-secret-key'
      );

      const res = await request(app)
        .get('/api/products')
        .set('Authorization', `Bearer ${fakeToken}`);

      expect(res.status).toBe(401);
    });
  });
});
```

### Test Cases สำหรับ Authorization

**`src/__tests__/security/authz.security.test.ts`**

```typescript
import { describe, it, expect, beforeEach } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Authorization Security (A01: Broken Access Control)', () => {
  let userToken: string;
  let adminToken: string;

  beforeEach(async () => {
    // Setup user and admin tokens
    await request(app)
      .post('/api/auth/register')
      .send({ email: 'user@test.com', password: 'User@123', name: 'User' });

    await request(app)
      .post('/api/auth/register')
      .send({ email: 'admin@test.com', password: 'Admin@123', name: 'Admin', role: 'admin' });

    const userRes = await request(app)
      .post('/api/auth/login')
      .send({ email: 'user@test.com', password: 'User@123' });
    userToken = userRes.body.token;

    const adminRes = await request(app)
      .post('/api/auth/login')
      .send({ email: 'admin@test.com', password: 'Admin@123' });
    adminToken = adminRes.body.token;
  });

  describe('Vertical Privilege Escalation', () => {
    it('should prevent normal user from accessing admin endpoints', async () => {
      const res = await request(app)
        .delete('/api/products/prod-1')
        .set('Authorization', `Bearer ${userToken}`);

      expect(res.status).toBe(403);
    });

    it('should prevent normal user from modifying roles', async () => {
      const res = await request(app)
        .put('/api/users/self')
        .set('Authorization', `Bearer ${userToken}`)
        .send({ role: 'admin' });

      expect([400, 403]).toContain(res.status);
    });
  });

  describe('Horizontal Privilege Escalation', () => {
    it('should prevent user from accessing another user profile', async () => {
      const res = await request(app)
        .get('/api/users/other-user-id')
        .set('Authorization', `Bearer ${userToken}`);

      expect([403, 404]).toContain(res.status);
    });

    it('should prevent user from modifying another user order', async () => {
      const res = await request(app)
        .put('/api/orders/other-user-order-id')
        .set('Authorization', `Bearer ${userToken}`)
        .send({ status: 'cancelled' });

      expect([403, 404]).toContain(res.status);
    });
  });

  describe('IDOR (Insecure Direct Object Reference)', () => {
    it('should not expose sequential IDs that can be enumerated', async () => {
      const res = await request(app)
        .get('/api/users/1')
        .set('Authorization', `Bearer ${userToken}`);

      // ควรใช้ UUID ไม่ใช่ sequential ID
      expect([403, 404]).toContain(res.status);
    });
  });
});
```

## 3. Injection Tests

**`src/__tests__/security/injection.security.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Injection Security (A03)', () => {
  describe('SQL Injection', () => {
    const sqlPayloads = [
      "' OR '1'='1",
      "'; DROP TABLE users; --",
      "' UNION SELECT * FROM users --",
      "1; DELETE FROM products",
      "' OR 1=1 --",
    ];

    it.each(sqlPayloads)(
      'should sanitize SQL injection payload: %s',
      async (payload) => {
        const res = await request(app)
          .get(`/api/products`)
          .query({ search: payload });

        // ต้องไม่ crash และไม่ return data ที่ไม่ควรได้
        expect(res.status).not.toBe(500);
        expect(JSON.stringify(res.body)).not.toMatch(/syntax error/i);
      }
    );
  });

  describe('XSS (Cross-Site Scripting)', () => {
    const xssPayloads = [
      '<script>alert("xss")</script>',
      '<img src=x onerror=alert("xss")>',
      'javascript:alert("xss")',
      '<svg onload=alert("xss")>',
      '"><script>alert(document.cookie)</script>',
    ];

    it.each(xssPayloads)(
      'should sanitize XSS payload: %s',
      async (payload) => {
        const res = await request(app)
          .post('/api/products')
          .set('Authorization', 'Bearer valid-admin-token')
          .send({
            name: payload,
            price: 100,
            category_id: 'cat-1',
          });

        if (res.status === 201) {
          // ถ้าสร้างได้ ข้อมูลต้องถูก sanitize
          expect(res.body.data.name).not.toContain('<script>');
          expect(res.body.data.name).not.toContain('onerror');
        }
      }
    );
  });

  describe('NoSQL Injection', () => {
    it('should reject object in query parameters', async () => {
      const res = await request(app)
        .post('/api/auth/login')
        .send({
          email: { $gt: '' },
          password: { $gt: '' },
        });

      expect(res.status).toBe(400);
    });
  });
});
```

## 4. Security Headers Tests

**`src/__tests__/security/headers.security.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Security Headers (A05: Security Misconfiguration)', () => {
  it('should set X-Content-Type-Options header', async () => {
    const res = await request(app).get('/api/health');
    expect(res.headers['x-content-type-options']).toBe('nosniff');
  });

  it('should set X-Frame-Options header', async () => {
    const res = await request(app).get('/api/health');
    expect(res.headers['x-frame-options']).toBe('DENY');
  });

  it('should not expose server information', async () => {
    const res = await request(app).get('/api/health');
    expect(res.headers['x-powered-by']).toBeUndefined();
  });

  it('should set Strict-Transport-Security header', async () => {
    const res = await request(app).get('/api/health');
    expect(res.headers['strict-transport-security']).toBeDefined();
  });

  it('should set Content-Security-Policy header', async () => {
    const res = await request(app).get('/api/health');
    expect(res.headers['content-security-policy']).toBeDefined();
  });

  it('should have proper CORS configuration', async () => {
    const res = await request(app)
      .options('/api/products')
      .set('Origin', 'https://malicious-site.com');

    // ไม่ควร allow origin ที่ไม่ได้อนุญาต
    expect(res.headers['access-control-allow-origin']).not.toBe('*');
  });
});
```

## 5. Rate Limiting Tests

**`src/__tests__/security/rate-limit.security.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Rate Limiting', () => {
  it('should return 429 after exceeding rate limit', async () => {
    const requests = [];

    // ส่ง requests จำนวนมากพร้อมกัน
    for (let i = 0; i < 100; i++) {
      requests.push(request(app).get('/api/products'));
    }

    const responses = await Promise.all(requests);
    const rateLimited = responses.filter((r) => r.status === 429);

    expect(rateLimited.length).toBeGreaterThan(0);
  });

  it('should include Retry-After header when rate limited', async () => {
    const requests = [];
    for (let i = 0; i < 100; i++) {
      requests.push(request(app).get('/api/products'));
    }

    const responses = await Promise.all(requests);
    const rateLimited = responses.find((r) => r.status === 429);

    if (rateLimited) {
      expect(rateLimited.headers['retry-after']).toBeDefined();
    }
  });
});
```

## 6. Data Exposure Tests

**`src/__tests__/security/data-exposure.security.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import app from '../../app';

describe('Data Exposure (A02: Cryptographic Failures)', () => {
  it('should never return password fields in any API response', async () => {
    // Register
    await request(app)
      .post('/api/auth/register')
      .send({ email: 'expose@test.com', password: 'Secure@123', name: 'Test' });

    // Login
    const loginRes = await request(app)
      .post('/api/auth/login')
      .send({ email: 'expose@test.com', password: 'Secure@123' });

    const body = JSON.stringify(loginRes.body);
    expect(body).not.toContain('Secure@123');
    expect(body).not.toContain('password_hash');
  });

  it('should not expose internal IDs or implementation details in errors', async () => {
    const res = await request(app).get('/api/products/non-existent-id');

    const body = JSON.stringify(res.body);
    expect(body).not.toMatch(/stack/i);
    expect(body).not.toMatch(/supabase/i);
    expect(body).not.toMatch(/postgresql/i);
  });

  it('should not expose environment variables or config in errors', async () => {
    const res = await request(app)
      .post('/api/auth/login')
      .send({ email: 'x', password: 'x' });

    const body = JSON.stringify(res.body);
    expect(body).not.toMatch(/JWT_SECRET/);
    expect(body).not.toMatch(/SUPABASE_URL/);
    expect(body).not.toMatch(/DATABASE_URL/);
  });
});
```

## Security Checklist

### Authentication & Authorization
- [ ] Passwords ถูก hash ด้วย bcrypt (cost >= 10)
- [ ] JWT มี expiration time (ไม่เกิน 24 ชั่วโมง)
- [ ] Refresh token mechanism ทำงานถูกต้อง
- [ ] Rate limiting สำหรับ login endpoint
- [ ] Role-based access control ทำงานถูกต้อง
- [ ] ไม่มี privilege escalation ได้

### Input Validation
- [ ] ทุก input ถูก validate ด้วย Zod schema
- [ ] ป้องกัน SQL Injection (ใช้ parameterized queries)
- [ ] ป้องกัน XSS (sanitize output)
- [ ] จำกัด request body size
- [ ] Validate file uploads (type, size)

### Security Headers
- [ ] Helmet.js ถูกติดตั้งและ configure
- [ ] CORS ถูกจำกัดเฉพาะ domains ที่อนุญาต
- [ ] X-Content-Type-Options: nosniff
- [ ] X-Frame-Options: DENY
- [ ] Strict-Transport-Security enabled

### Data Protection
- [ ] Passwords ไม่โผล่ใน API response
- [ ] Error messages ไม่เปิดเผย implementation details
- [ ] Environment variables ไม่ถูก commit
- [ ] Sensitive data ถูก encrypt ใน database
- [ ] Logs ไม่บันทึก sensitive data

### Dependencies
- [ ] `npm audit` ไม่มี high/critical vulnerabilities
- [ ] Dependencies ถูก update เป็นประจำ
- [ ] ไม่ใช้ deprecated packages

## Best Practices

### DO's
- รัน `npm audit` **ทุกสัปดาห์** (หรือใน CI)
- ใช้ **parameterized queries** เสมอ (ไม่ใช่ string concatenation)
- **Validate input** ทุก endpoint ด้วย Zod
- **Hash passwords** ด้วย bcrypt (cost >= 10)
- ใช้ **Helmet.js** สำหรับ security headers
- **Log** security events (failed logins, unauthorized access)
- ใช้ **HTTPS** ใน production เสมอ

### DON'Ts
- อย่า **hardcode secrets** ในโค้ด
- อย่าส่ง **error stack traces** ให้ client
- อย่าใช้ `eval()` หรือ `Function()` constructor
- อย่าเก็บ **JWT ใน localStorage** (ใช้ httpOnly cookie)
- อย่า **trust client-side validation** อย่างเดียว
- อย่าใช้ **CORS: \*** ใน production
- อย่า **log passwords** หรือ tokens
