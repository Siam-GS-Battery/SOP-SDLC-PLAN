# 6.2 Unit Test Guide

> แนวทางการเขียน Unit Test สำหรับ Frontend (React) และ Backend (Node.js/Express)

---

## วัตถุประสงค์

Unit Test คือการทดสอบ **หน่วยย่อยที่สุดของโค้ด** (function, component, service) แบบแยกส่วน เพื่อ:
1. ตรวจสอบว่าแต่ละหน่วยทำงานถูกต้องตาม spec
2. ตรวจจับ bug ได้เร็วที่สุด (ก่อน push code)
3. เป็นเอกสารประกอบโค้ดที่ "รันได้"
4. ป้องกัน regression เมื่อแก้ไขโค้ด

---

## เครื่องมือที่ใช้

| เครื่องมือ | วัตถุประสงค์ | ติดตั้ง |
|:----------|:------------|:--------|
| **Vitest** | Test runner + assertions | `npm install -D vitest` |
| **React Testing Library** | Test React components | `npm install -D @testing-library/react @testing-library/jest-dom @testing-library/user-event` |
| **jsdom** | จำลอง DOM ใน Node.js | `npm install -D jsdom` |
| **MSW** | Mock API requests | `npm install -D msw` |

## Naming Convention

### ชื่อไฟล์

```
<ชื่อไฟล์ที่ test>.test.ts    # สำหรับ .ts files
<ชื่อไฟล์ที่ test>.test.tsx   # สำหรับ .tsx files (React components)
```

### ชื่อ Test Cases

ใช้รูปแบบ: **"should [พฤติกรรมที่คาดหวัง] when [เงื่อนไข]"**

```typescript
// ✅ ดี — อธิบายพฤติกรรม
it('should return formatted price when given a number')
it('should show error message when email is invalid')
it('should disable submit button when form is incomplete')

// ❌ ไม่ดี — กว้างเกินไป
it('works correctly')
it('test formatPrice')
it('handles error')
```

---

## Pattern: Arrange-Act-Assert (AAA)

ทุก test case ควรมี 3 ส่วน:

```typescript
it('should calculate total with tax', () => {
  // Arrange — เตรียมข้อมูล
  const price = 100;
  const taxRate = 0.07;

  // Act — ทำ action
  const result = calculateTotal(price, taxRate);

  // Assert — ตรวจสอบผลลัพธ์
  expect(result).toBe(107);
});
```

## ตัวอย่าง: Unit Test สำหรับ Frontend

### 1. Test Utility Functions

**`src/utils/format.ts`**

```typescript
export function formatPrice(price: number): string {
  return new Intl.NumberFormat('th-TH', {
    style: 'currency',
    currency: 'THB',
  }).format(price);
}

export function truncateText(text: string, maxLength: number): string {
  if (text.length <= maxLength) return text;
  return text.slice(0, maxLength) + '...';
}
```

**`src/utils/format.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import { formatPrice, truncateText } from './format';

describe('formatPrice', () => {
  it('should format number as Thai Baht currency', () => {
    expect(formatPrice(1000)).toBe('฿1,000.00');
  });

  it('should handle decimal numbers', () => {
    expect(formatPrice(99.5)).toBe('฿99.50');
  });

  it('should handle zero', () => {
    expect(formatPrice(0)).toBe('฿0.00');
  });
});

describe('truncateText', () => {
  it('should return full text when shorter than maxLength', () => {
    expect(truncateText('Hello', 10)).toBe('Hello');
  });

  it('should truncate and add ellipsis when text exceeds maxLength', () => {
    expect(truncateText('Hello World', 5)).toBe('Hello...');
  });

  it('should return full text when equal to maxLength', () => {
    expect(truncateText('Hello', 5)).toBe('Hello');
  });
});
```

### 2. Test React Components

**`src/components/Button.tsx`**

```tsx
interface ButtonProps {
  label: string;
  onClick: () => void;
  disabled?: boolean;
  variant?: 'primary' | 'secondary';
}

export function Button({ label, onClick, disabled = false, variant = 'primary' }: ButtonProps) {
  return (
    <button
      className={`btn btn-${variant}`}
      onClick={onClick}
      disabled={disabled}
    >
      {label}
    </button>
  );
}
```

**`src/components/Button.test.tsx`**

```tsx
import { describe, it, expect, vi } from 'vitest';
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { Button } from './Button';

describe('Button', () => {
  it('should render with label text', () => {
    render(<Button label="Click me" onClick={() => {}} />);
    expect(screen.getByText('Click me')).toBeInTheDocument();
  });

  it('should call onClick when clicked', async () => {
    const handleClick = vi.fn();
    render(<Button label="Click me" onClick={handleClick} />);

    await userEvent.click(screen.getByText('Click me'));

    expect(handleClick).toHaveBeenCalledTimes(1);
  });

  it('should not call onClick when disabled', async () => {
    const handleClick = vi.fn();
    render(<Button label="Click me" onClick={handleClick} disabled />);

    await userEvent.click(screen.getByText('Click me'));

    expect(handleClick).not.toHaveBeenCalled();
  });

  it('should apply primary variant class by default', () => {
    render(<Button label="Click me" onClick={() => {}} />);
    expect(screen.getByText('Click me')).toHaveClass('btn-primary');
  });

  it('should apply secondary variant class when specified', () => {
    render(<Button label="Click me" onClick={() => {}} variant="secondary" />);
    expect(screen.getByText('Click me')).toHaveClass('btn-secondary');
  });
});
```

### 3. Test Custom Hooks

**`src/hooks/useCounter.ts`**

```typescript
import { useState, useCallback } from 'react';

export function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue);

  const increment = useCallback(() => setCount((c) => c + 1), []);
  const decrement = useCallback(() => setCount((c) => c - 1), []);
  const reset = useCallback(() => setCount(initialValue), [initialValue]);

  return { count, increment, decrement, reset };
}
```

**`src/hooks/useCounter.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import { renderHook, act } from '@testing-library/react';
import { useCounter } from './useCounter';

describe('useCounter', () => {
  it('should initialize with default value 0', () => {
    const { result } = renderHook(() => useCounter());
    expect(result.current.count).toBe(0);
  });

  it('should initialize with custom value', () => {
    const { result } = renderHook(() => useCounter(10));
    expect(result.current.count).toBe(10);
  });

  it('should increment count', () => {
    const { result } = renderHook(() => useCounter());

    act(() => result.current.increment());

    expect(result.current.count).toBe(1);
  });

  it('should decrement count', () => {
    const { result } = renderHook(() => useCounter(5));

    act(() => result.current.decrement());

    expect(result.current.count).toBe(4);
  });

  it('should reset to initial value', () => {
    const { result } = renderHook(() => useCounter(10));

    act(() => {
      result.current.increment();
      result.current.increment();
      result.current.reset();
    });

    expect(result.current.count).toBe(10);
  });
});
```

## ตัวอย่าง: Unit Test สำหรับ Backend

### 1. Test Service Layer

**`src/services/product.service.test.ts`**

```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { ProductService } from './product.service';
import { ProductRepository } from '../repositories/product.repository';

// Mock repository
vi.mock('../repositories/product.repository');

describe('ProductService', () => {
  let service: ProductService;
  let mockRepo: vi.Mocked<ProductRepository>;

  beforeEach(() => {
    mockRepo = new ProductRepository() as vi.Mocked<ProductRepository>;
    service = new ProductService(mockRepo);
    vi.clearAllMocks();
  });

  describe('getAll', () => {
    it('should return all products', async () => {
      const mockProducts = [
        { id: '1', name: 'Product A', price: 100 },
        { id: '2', name: 'Product B', price: 200 },
      ];
      mockRepo.findAll.mockResolvedValue(mockProducts);

      const result = await service.getAll();

      expect(result).toEqual(mockProducts);
      expect(mockRepo.findAll).toHaveBeenCalledTimes(1);
    });
  });

  describe('getById', () => {
    it('should return product when found', async () => {
      const mockProduct = { id: '1', name: 'Product A', price: 100 };
      mockRepo.findById.mockResolvedValue(mockProduct);

      const result = await service.getById('1');

      expect(result).toEqual(mockProduct);
      expect(mockRepo.findById).toHaveBeenCalledWith('1');
    });

    it('should throw error when product not found', async () => {
      mockRepo.findById.mockResolvedValue(null);

      await expect(service.getById('999')).rejects.toThrow('Product not found');
    });
  });

  describe('create', () => {
    it('should create and return new product', async () => {
      const input = { name: 'New Product', price: 150 };
      const created = { id: '3', ...input };
      mockRepo.create.mockResolvedValue(created);

      const result = await service.create(input);

      expect(result).toEqual(created);
      expect(mockRepo.create).toHaveBeenCalledWith(input);
    });

    it('should throw error when price is negative', async () => {
      const input = { name: 'Bad Product', price: -10 };

      await expect(service.create(input)).rejects.toThrow('Price must be positive');
    });
  });
});
```

### 2. Test Controller Layer

**`src/controllers/product.controller.test.ts`**

```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { Request, Response } from 'express';
import { ProductController } from './product.controller';
import { ProductService } from '../services/product.service';

vi.mock('../services/product.service');

describe('ProductController', () => {
  let controller: ProductController;
  let mockService: vi.Mocked<ProductService>;
  let mockReq: Partial<Request>;
  let mockRes: Partial<Response>;

  beforeEach(() => {
    mockService = new ProductService(null as any) as vi.Mocked<ProductService>;
    controller = new ProductController(mockService);

    mockReq = {};
    mockRes = {
      json: vi.fn().mockReturnThis(),
      status: vi.fn().mockReturnThis(),
    };

    vi.clearAllMocks();
  });

  describe('getAll', () => {
    it('should return 200 with products list', async () => {
      const products = [{ id: '1', name: 'Product A', price: 100 }];
      mockService.getAll.mockResolvedValue(products);

      await controller.getAll(mockReq as Request, mockRes as Response);

      expect(mockRes.json).toHaveBeenCalledWith({ data: products });
    });
  });

  describe('getById', () => {
    it('should return 200 with product when found', async () => {
      const product = { id: '1', name: 'Product A', price: 100 };
      mockReq.params = { id: '1' };
      mockService.getById.mockResolvedValue(product);

      await controller.getById(mockReq as Request, mockRes as Response);

      expect(mockRes.json).toHaveBeenCalledWith({ data: product });
    });

    it('should return 404 when product not found', async () => {
      mockReq.params = { id: '999' };
      mockService.getById.mockRejectedValue(new Error('Product not found'));

      await controller.getById(mockReq as Request, mockRes as Response);

      expect(mockRes.status).toHaveBeenCalledWith(404);
      expect(mockRes.json).toHaveBeenCalledWith({ error: 'Product not found' });
    });
  });
});
```

### 3. Test Validation (Zod)

**`src/validators/product.validator.test.ts`**

```typescript
import { describe, it, expect } from 'vitest';
import { createProductSchema } from './product.validator';

describe('createProductSchema', () => {
  it('should validate correct input', () => {
    const input = { name: 'Product A', price: 100, category_id: '1' };
    const result = createProductSchema.safeParse(input);

    expect(result.success).toBe(true);
  });

  it('should reject empty name', () => {

    const result = createProductSchema.safeParse(input);

    expect(result.success).toBe(false);
  });

  it('should reject negative price', () => {
    const input = { name: 'Product A', price: -1, category_id: '1' };
    const result = createProductSchema.safeParse(input);

    expect(result.success).toBe(false);
  });

  it('should reject missing required fields', () => {
    const input = { name: 'Product A' };
    const result = createProductSchema.safeParse(input);

    expect(result.success).toBe(false);
  });
});
```

## การ Mock

### เมื่อไหร่ควร Mock

| ควร Mock | ไม่ควร Mock |
|:---------|:-----------|
| External APIs (fetch, axios) | Pure functions (utils, helpers) |
| Database queries | Business logic |
| Third-party libraries (email, payment) | Simple data transformations |
| Date/Time (`Date.now()`) | Internal module interactions |
| Environment variables | Constants |

### วิธี Mock ที่ใช้บ่อย

```typescript
// Mock module
vi.mock('../services/api');

// Mock function
const mockFn = vi.fn();
mockFn.mockReturnValue('value');         // sync
mockFn.mockResolvedValue('value');       // async success
mockFn.mockRejectedValue(new Error());  // async error

// Mock timer
vi.useFakeTimers();
vi.advanceTimersByTime(1000);
vi.useRealTimers();

// Spy on existing function
const spy = vi.spyOn(object, 'method');
expect(spy).toHaveBeenCalled();
```

## Checklist ก่อน Push

- [ ] ทุก test case ผ่าน (`npm run test:run`)
- [ ] Coverage ผ่านเกณฑ์ขั้นต่ำ (`npm run test:coverage`)
- [ ] ไม่มี `it.skip` หรือ `describe.skip` ที่ลืมเอาออก
- [ ] ไม่มี `it.only` หรือ `describe.only` ที่ลืมเอาออก
- [ ] Test ไม่ขึ้นอยู่กับลำดับการรัน (independent)
- [ ] Mock ถูก reset ใน `beforeEach` ทุกครั้ง

## Best Practices

### DO's
- เขียน test **ก่อนหรือพร้อม** กับ production code
- **1 test case = 1 assertion** (หรือ assertions ที่เกี่ยวข้องกัน)
- ใช้ `describe` จัดกลุ่ม test ตาม function/feature
- ใช้ `beforeEach` สำหรับ setup ที่ซ้ำกัน
- Test ทั้ง **happy path** และ **edge cases**
- Test **error handling** ด้วย

### DON'Ts
- อย่า test **implementation details** (เช่น state ภายใน component)
- อย่า mock **ทุกอย่าง** — mock เฉพาะ external dependencies
- อย่าเขียน test ที่ **ช้า** (unit test ควร < 100ms ต่อ case)
- อย่า **copy-paste** test — ใช้ `it.each` สำหรับ data-driven tests
- อย่าทดสอบ **third-party library** (เช่น test ว่า React render ถูกหรือไม่)

## Data-Driven Tests ด้วย `it.each`

```typescript
describe('isValidEmail', () => {
  it.each([
    ['user@example.com', true],
    ['user@sub.example.com', true],
    ['invalid-email', false],
    ['@example.com', false],
    ['user@', false],
    ['', false],
  ])('should return %s for input "%s"', (input, expected) => {
    expect(isValidEmail(input)).toBe(expected);
  });
});
```
