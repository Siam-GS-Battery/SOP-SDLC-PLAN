# 4.2 Import UI from Figma Make

## วัตถุประสงค์

นำเข้า Code และ Design Assets จาก Figma Make ที่สร้างจาก Acceptance Criteria (AC) เข้าสู่โปรเจกต์

---

## 1. Export Code จาก Figma Make

1. เปิดไฟล์ Figma Make ที่สร้างจาก AC
2. เลือก Page/Component ที่ต้องการ
3. Export code ออกมา (React + Tailwind)
4. วาง code ลงในโฟลเดอร์ที่เหมาะสมตาม [Code Standard Guide](Code_Standard_Guide.md#2-file--folder-structure)

### Export Wireframe Images (สำหรับอ้างอิง)

```bash
mkdir -p frontend/picture/{pages,components}
```

**การตั้งชื่อไฟล์:**
```
frontend/picture/
├── pages/
│   ├── 01_home.png
│   ├── 02_login.png
│   ├── 03_product_list.png
│   └── 04_product_detail.png
└── components/
    ├── header.png
    ├── footer.png
    └── product_card.png
```

## 2. Export Design Tokens

ดึง Colors, Typography, Spacing จาก Figma Make มาเป็น TypeScript:

**`src/constants/designTokens.ts`:**
```typescript
export const colors = {
  primary: { 50: '#eff6ff', 500: '#3b82f6', 600: '#2563eb', 700: '#1d4ed8' },
  secondary: { 50: '#f8fafc', 500: '#64748b', 600: '#475569' },
  success: '#22c55e',
  warning: '#f59e0b',
  error: '#ef4444',
};

export const typography = {
  fontFamily: { sans: ['IBM Plex Sans Thai', 'sans-serif'] },
  fontSize: {
    h1: ['2.25rem', { lineHeight: '2.5rem', fontWeight: '700' }],
    h2: ['1.875rem', { lineHeight: '2.25rem', fontWeight: '600' }],
    body: ['1rem', { lineHeight: '1.5rem', fontWeight: '400' }],
    small: ['0.875rem', { lineHeight: '1.25rem', fontWeight: '400' }],
  },
};

export const spacing = {
  page: { x: '1.5rem', y: '2rem' },
  card: { x: '1rem', y: '0.75rem' },
  gap: { sm: '0.5rem', md: '1rem', lg: '1.5rem' },
};
```

### ใส่ใน Tailwind Config

```javascript
// tailwind.config.js
import { colors, typography } from './src/constants/designTokens';

export default {
  theme: {
    extend: {
      colors: colors,
      fontFamily: typography.fontFamily,
    },
  },
};
```
