# 4.2 Import UI from Figma Make

## วัตถุประสงค์

นำ Code จาก Figma Make ที่สร้างด้วย AI จาก Acceptance Criteria (AC) มาเป็นฐาน Frontend ของโปรเจกต์

---

## Figma Make คืออะไร?

Figma Make เป็น AI Design Tool ของ Figma ที่สร้าง **functional prototype** จาก text prompt ได้เลย — ได้ทั้ง UI, interaction, และ code (React + CSS) พร้อมใช้งาน

**สิ่งที่ Figma Make ทำได้:**
- สร้าง responsive layouts จาก prompt
- Generate React + Tailwind code
- สร้าง DataContext (โครงสร้างข้อมูลจำลอง)
- สร้าง interactive prototype ที่ทดสอบได้
- Export code ออกมาใช้ในโปรเจกต์จริง

---

## 1. สร้าง UI ด้วย Figma Make

### 1.1 เปิด Figma Make

1. เปิด Figma → เลือก **Figma Make** (หรือกด `⌘+K` / `Ctrl+K`)
2. เลือก template หรือเริ่มจาก blank

### 1.2 เขียน Prompt จาก AC

นำ Acceptance Criteria มาเขียนเป็น prompt ให้ Figma Make:

```
ตัวอย่าง prompt:
"E-commerce web application with:
- Login/Register page with email and password
- Product listing page with search bar, category filter, and grid layout
- Product detail page with image gallery, price, add to cart button
- Shopping cart page with quantity adjustment and checkout
- Admin dashboard with product management table
- Use modern design, clean layout, Thai language support"
```

> **Tips:** ยิ่ง prompt ละเอียดตาม AC ยิ่งได้ UI ที่ตรงกับความต้องการ

### 1.3 ใช้ Make Kits (เพิ่ม context)

Make Kits ช่วยให้ Figma Make เข้าใจ design system ของโปรเจกต์:

- **npm packages** — ระบุ library ที่ใช้ (เช่น react-icons, date-fns)
- **Variables & Styles** — import จาก Figma library ของทีม
- **Guidelines** — เขียนกฎการออกแบบ (เช่น "ใช้ IBM Plex Sans Thai", "primary color: #2563eb")

### 1.4 ใช้ Make Attachments (แนบไฟล์)

แนบไฟล์เข้า prompt เพื่อให้ได้ผลลัพธ์ที่ตรงกว่า:

| ไฟล์ที่แนบได้ | ใช้เมื่อ |
|--------------|---------|
| PDF, Markdown | แนบ AC / User Stories / Requirements |
| JSON, CSV | แนบ sample data / mock data structure |
| TSX, JS, CSS | แนบ code เดิมที่ต้องการต่อยอด |
| PNG, JPEG | แนบ wireframe / reference design |

## 2. Export Code จาก Figma Make

### 2.1 Download Code

1. เปิด Figma Make file ที่สร้างเสร็จแล้ว
2. คลิก tab **"Code"** เพื่อดู code ที่ generate
3. คลิก **"Download code"** ที่มุมขวา
4. ได้โปรเจกต์ React พร้อม components, pages, styles

### 2.2 Copy Preview as Design Layers

ถ้าต้องการแก้ไข design ต่อใน Figma Design:

1. เปิด preview ใน Figma Make
2. คลิก **"Copy preview as design layers"**
3. วางใน Figma Design file เพื่อปรับแก้ต่อ

---

## 3. นำ Code เข้าโปรเจกต์

### 3.1 วาง Code ในโครงสร้างที่ถูกต้อง

```bash
# แตก downloaded code
unzip figma-make-export.zip -d figma-export/

# Copy components เข้าโปรเจกต์
cp -r figma-export/components/* frontend/src/components/
cp -r figma-export/pages/* frontend/src/pages/
```

**จัดไฟล์ตาม convention:**
```
frontend/src/
├── components/
│   ├── common/          ← Button, Input, Modal จาก Figma Make
│   ├── layout/          ← Header, Footer, Sidebar
│   └── features/        ← Feature-specific components
│       ├── auth/        ← LoginForm, RegisterForm
│       └── products/    ← ProductCard, ProductList
├── pages/               ← HomePage, ProductPage, CartPage
└── ...
```

> ดูรายละเอียดโครงสร้างที่ [Code Standard Guide — Section 2](Code_Standard_Guide.md#2-file--folder-structure)

### 3.2 ตรวจสอบและปรับ Code

Figma Make generate code ที่ใช้งานได้ แต่ควรตรวจสอบ:

- [ ] Component naming ตรงตาม convention (PascalCase)
- [ ] Import paths ถูกต้องตามโครงสร้างโปรเจกต์
- [ ] Tailwind classes ทำงานถูกต้อง
- [ ] ลบ code ที่ไม่จำเป็นออก (unused imports, placeholder data)

### 3.3 เก็บ DataContext ไว้สำหรับขั้นตอนถัดไป

Figma Make จะสร้าง **DataContext** (โครงสร้างข้อมูลจำลอง) ไว้ใน code:

```typescript
// ตัวอย่าง DataContext ที่ Figma Make สร้าง
const products = [
  { id: 1, name: "Product A", price: 500, category: "Electronics", image: "..." },
  { id: 2, name: "Product B", price: 300, category: "Clothing", image: "..." },
];

const users = [
  { id: 1, email: "admin@example.com", role: "admin", firstName: "Admin" },
];
```

> **สำคัญ:** เก็บ DataContext ไว้ — ในขั้นตอน [4.3 Database from DataContext](4.3_Database_Design.md) จะใช้ Claude อ่าน DataContext นี้เพื่อสร้าง SQL Schema

## 4. Export Wireframe Images (อ้างอิง)

บันทึก screenshot ของแต่ละหน้าไว้สำหรับอ้างอิง:

```bash
mkdir -p frontend/picture/{pages,components}
```

```
frontend/picture/
├── pages/
│   ├── 01_home.png
│   ├── 02_login.png
│   ├── 03_product_list.png
│   └── 04_product_detail.png
└── components/
    ├── header.png
    └── product_card.png
```
