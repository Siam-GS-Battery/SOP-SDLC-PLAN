# 5.2 Import Wireframes — นำเข้า Wireframe

## วัตถุประสงค์

นำเข้า Wireframe และ Design Assets จาก Figma มาเก็บในโปรเจกต์ เพื่อใช้เป็นแนวทางในการพัฒนา Frontend และอ้างอิงในการวิเคราะห์โครงสร้างหน้าเว็บ

---

## ขั้นตอนการทำ

### 1. Export Wireframes จาก Figma

#### 1.1 เปิด Figma Design File

1. เปิด Figma project ที่มี Wireframes/Mockups
2. ไปที่ Frame หรือ Page ที่ต้องการ export

#### 1.2 Export แต่ละหน้าเป็นรูปภาพ

**วิธีที่ 1: Export ทีละหน้า**

1. เลือก Frame ที่ต้องการ (เช่น HomePage, LoginPage)
2. คลิกขวา → **Export...**
3. ตั้งค่า Export:
   - **Format**: PNG (แนะนำ) หรือ JPG
   - **Scale**: 2x (สำหรับ Retina displays)
   - **Prefix/Suffix**: (Optional) เพิ่ม @2x
4. คลิก **Export [Frame Name]**
5. บันทึกไฟล์ไปที่โฟลเดอร์ `frontend/picture/`

**วิธีที่ 2: Export หลายหน้าพร้อมกัน**

1. เลือกหลาย Frames (กด Shift + คลิก)
2. คลิกขวา → **Export...**
3. เลือก Format และ Scale
4. คลิก **Export X Frames**
5. บันทึกไฟล์ไปที่โฟลเดอร์ `frontend/picture/`

**ตัวอย่างการตั้งชื่อไฟล์:**
```
HomePage.png
LoginPage.png
RegisterPage.png
DashboardPage.png
ProductListPage.png
ProductDetailPage.png
CartPage.png
CheckoutPage.png
ProfilePage.png
```

#### 1.3 Export Components (Optional)

หาก Wireframe มี Component Designs แยก:

1. Export components เช่น:
   - `Button.png`
   - `InputField.png`
   - `Card.png`
   - `Modal.png`
   - `Navigation.png`
2. เก็บในโฟลเดอร์ `frontend/picture/components/`

### 4. สร้าง Tailwind Config จาก Design Tokens

#### 4.1 อัพเดท `tailwind.config.js`

```javascript

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        primary: colors.primary,
        gray: colors.gray,
        success: colors.success,
        error: colors.error,
        warning: colors.warning,
        info: colors.info,
      },
      fontFamily: {
        sans: typography.fontFamily.sans,
      },
      fontSize: typography.fontSize,
      fontWeight: typography.fontWeight,
      lineHeight: typography.lineHeight,
      spacing: spacing,
    },
  },
  plugins: [],
}
```

### 5. Export Icons & Assets

#### 5.1 Export Icons จาก Figma

1. เลือก Icon ที่ต้องการ
2. คลิกขวา → **Copy/Paste as** → **Copy as SVG**
3. วางใน text editor และบันทึกเป็น `.svg`
4. เก็บในโฟลเดอร์ `src/assets/icons/`

**หรือใช้ Plugin:**
- ติดตั้ง **Iconify** plugin ใน Figma
- Export เป็น React components

#### 5.2 ใช้ React Icons Library (แนะนำ)

```bash
# ติดตั้ง react-icons
npm install react-icons

# ใช้งาน
import { FaUser, FaShoppingCart, FaHeart } from 'react-icons/fa';
import { MdDashboard, MdSettings } from 'react-icons/md';
```

#### 7.2 สร้าง Component Library

**ตัวอย่าง `src/components/common/Button.tsx`:**

```typescript
import React from 'react';
import clsx from 'clsx';

interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'danger';
  size?: 'sm' | 'md' | 'lg';
  children: React.ReactNode;
  onClick?: () => void;
  disabled?: boolean;
}

export function Button({
  variant = 'primary',
  size = 'md',
  children,
  onClick,
  disabled = false,
}: ButtonProps) {
  const baseClasses = 'rounded-lg font-medium transition-colors';

  const variantClasses = {
    primary: 'bg-primary-600 text-white hover:bg-primary-700',
    secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300',
    danger: 'bg-error text-white hover:bg-red-700',
  };

  const sizeClasses = {
    sm: 'px-3 py-1.5 text-sm',
    md: 'px-4 py-2 text-base',
    lg: 'px-6 py-3 text-lg',
  };

  return (
    <button
      className={clsx(
        baseClasses,
        variantClasses[variant],
        sizeClasses[size],
        disabled && 'opacity-50 cursor-not-allowed'
      )}
      onClick={onClick}
      disabled={disabled}
    >
      {children}
    </button>
  );
}
```
