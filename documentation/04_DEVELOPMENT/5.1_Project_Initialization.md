# 5.1 Project Initialization — การตั้งค่าโปรเจกต์

## วัตถุประสงค์

การตั้งค่าโปรเจกต์เป็นขั้นตอนแรกของการพัฒนา ต้องสร้าง repository, โครงสร้างโฟลเดอร์, และติดตั้ง tools ที่จำเป็นให้พร้อมใช้งาน

---

## ขั้นตอนการทำ

### 1. สร้าง GitHub Repository

#### 1.1 สร้าง Repository บน GitHub

1. ไปที่ [github.com](https://github.com)
2. คลิก **New repository**
3. กรอกข้อมูล:
   - **Repository name**: `DM-S-09-project-name`
   - **Description**: คำอธิบายโปรเจกต์สั้นๆ
   - **Visibility**: Public / Private
   - ✅ เลือก **Add a README file**
   - ✅ เลือก **Add .gitignore** → Template: **Node**
   - เลือก **License** (แนะนำ: MIT)
4. คลิก **Create repository**

#### 1.2 Clone Repository มาที่เครื่อง

```bash
# Clone repository
git clone https://github.com/username/project-name.git

# เข้าไปในโฟลเดอร์
cd project-name

# ตรวจสอบ remote
git remote -v
```

#### 1.3 สร้าง Branch Structure

```bash
# สร้าง develop branch
git checkout -b develop

# Push develop branch ขึ้น GitHub
git push -u origin develop

# กลับไปที่ main
git checkout main
```

**Branch Strategy:**
- `main` → Production branch (protected)
- `develop` → Development branch
- `feature/*` → Feature branches
- `bugfix/*` → Bug fix branches
- `hotfix/*` → Hotfix branches

### 3. ติดตั้ง Frontend (React + TypeScript + Vite + Tailwind)

#### 3.1 สร้างโปรเจกต์ React + Vite

```bash
# เข้าไปในโฟลเดอร์ frontend
cd frontend

# สร้างโปรเจกต์ด้วย Vite
npm create vite@latest . -- --template react-ts

# ติดตั้ง dependencies
npm install
```

#### 3.2 ติดตั้ง Tailwind CSS

```bash
# ติดตั้ง Tailwind CSS และ dependencies
npm install -D tailwindcss postcss autoprefixer

# สร้างไฟล์ config
npx tailwindcss init -p
```

**แก้ไข `tailwind.config.js`:**

```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      fontFamily: {
        sans: ['IBM Plex Sans Thai', 'sans-serif'],
      },
    },
  },
  plugins: [],
}
```

**สร้างไฟล์ `src/index.css`:**

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

**Import ใน `src/main.tsx`:**

```typescript
import './index.css'
```

#### 3.3 ติดตั้ง Libraries สำคัญ

```bash
# React Router DOM
npm install react-router-dom

# State Management (Zustand)
npm install zustand

# HTTP Client (Axios)
npm install axios

# Form Handling
npm install react-hook-form

npm install @hookform/resolvers

# UI Libraries (Optional)
npm install clsx
npm install react-icons

# Date/Time
npm install date-fns
```

#### 3.4 ติดตั้ง Dev Dependencies

```bash
# TypeScript types
npm install -D @types/node

# ESLint
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D eslint-plugin-react eslint-plugin-react-hooks

```

### 4. ติดตั้ง Backend (Node.js + TypeScript + Express)

#### 4.1 สร้างโปรเจกต์ Node.js

```bash
# กลับไปที่ root folder
cd ..

# เข้าไปในโฟลเดอร์ backend
cd backend

# Initialize npm
npm init -y
```

#### 4.2 ติดตั้ง Dependencies

```bash
# Express และ TypeScript
npm install express
npm install dotenv
npm install cors

# Database (PostgreSQL + Supabase)
npm install @supabase/supabase-js
npm install pg

# Authentication
npm install jsonwebtoken
npm install bcrypt

# Validation
npm install zod

# Dev Dependencies
npm install -D typescript @types/node @types/express
npm install -D @types/cors @types/jsonwebtoken @types/bcrypt
npm install -D ts-node nodemon
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D prettier
```

#### 4.3 สร้างไฟล์ `tsconfig.json`

```bash
npx tsc --init
```

**แก้ไข `tsconfig.json`:**

```json
{
  "compilerOptions": {

  "exclude": ["node_modules", "dist"]
```

```javascript
module.exports = {
  root: true,
```

```javascript
module.exports = {
  semi: true,
```

#### 4.6 เพิ่ม Scripts ใน `package.json`

```json
{
  "scripts": {
    "dev": "nodemon src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js",
    "lint": "eslint . --ext .ts",
    "lint:fix": "eslint . --ext .ts --fix",
    "format": "prettier --write \"src/**/*.ts\""
  }
}
```

#### 4.7 สร้าง Entry Point

**สร้างไฟล์ `src/server.ts`:**

```typescript
import express from 'express';
import cors from 'cors';
import dotenv from 'dotenv';

dotenv.config();

const app = express();
const PORT = process.env.PORT || 3000;

// Middleware
app.use(cors());
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// Health check route
app.get('/health', (req, res) => {
  res.json({ status: 'OK', message: 'Server is running' });
});

// Start server
app.listen(PORT, () => {
  console.log(`🚀 Server is running on http://localhost:${PORT}`);
});
```

#### 4.8 ทดสอบ Backend

```bash
# รัน dev server
npm run dev

# ทดสอบด้วย curl หรือ browser
curl http://localhost:3000/health
```

### 6. ตั้งค่า Git Hooks (Husky)

#### 6.1 ติดตั้ง Husky

```bash
# กลับไปที่ root folder
cd ..

# ติดตั้ง Husky
npm init -y
npm install -D husky lint-staged

# Initialize Husky
npx husky install

# เพิ่ม prepare script
npm pkg set scripts.prepare="husky install"
```

#### 6.2 สร้าง Pre-commit Hook

```bash
# สร้าง pre-commit hook
npx husky add .husky/pre-commit "npx lint-staged"
```

#### 6.3 ตั้งค่า lint-staged

**เพิ่มใน root `package.json`:**

```json
{
  "lint-staged": {
    "frontend/src/**/*.{ts,tsx}": [
      "cd frontend && npm run lint:fix",
      "cd frontend && npm run format"
    ],
    "backend/src/**/*.ts": [
      "cd backend && npm run lint:fix",
      "cd backend && npm run format"
    ]
  }
}
```
