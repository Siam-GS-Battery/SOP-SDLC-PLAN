```typescript
interface CartState {
  items: CartItem[];
  total: number;
  itemCount: number;

  // Actions
  addItem: (product: Product, quantity?: number) => void;
  removeItem: (productId: number) => void;
  updateQuantity: (productId: number, quantity: number) => void;
  clearCart: () => void;
  calculateTotal: () => void;
}

export const useCartStore = create<CartState>((set, get) => ({
  items: [],
  total: 0,
  itemCount: 0,

  addItem: (product, quantity = 1) => {
    // Implementation
  },

  removeItem: (productId) => {
    // Implementation
  },

  updateQuantity: (productId, quantity) => {
    // Implementation
  },

  clearCart: () => {
    set({ items: [], total: 0, itemCount: 0 });
  },

  calculateTotal: () => {
    const { items } = get();
    const total = items.reduce((sum, item) => sum + item.subtotal, 0);
    const itemCount = items.reduce((sum, item) => sum + item.quantity, 0);
    set({ total, itemCount });
  },
}));
```

### 5. วิเคราะห์ User Flows

#### 5.1 สร้าง User Flow Diagrams

**ตัวอย่าง: Shopping Flow**

```
1. Browse Products
   └─> View Product List
       └─> Apply Filters (Category, Price, Rating)
       └─> Search Products
       └─> Click Product
           └─> View Product Detail
               ├─> Add to Cart
               │   └─> Continue Shopping (back to list)
               │   └─> Go to Cart
               │       └─> Update Quantities
               │       └─> Remove Items
               │       └─> Proceed to Checkout
               │           ├─> Login (if not authenticated)
               │           └─> Fill Shipping Info
               │               └─> Select Payment Method
               │                   └─> Confirm Order
               │                       └─> Order Success Page
               └─> View Reviews
```

**ตัวอย่าง: Authentication Flow**

```
1. Guest User
   └─> Click Login/Register
       ├─> Login
       │   └─> Enter Email + Password
       │       ├─> Success → Redirect to previous page
       │       └─> Error → Show error message
       └─> Register
           └─> Enter Email + Password + Name
               ├─> Success → Auto login → Redirect
               └─> Error → Show validation errors
```

#### 5.2 สร้างไฟล์ User Flows

**สร้างไฟล์ `docs/user-flows.md`:**

```markdown
# User Flows

## 1. Product Discovery Flow
1. User lands on homepage
2. User clicks "Shop Now" or navigates to Products
3. User applies filters (category, price range)
4. User searches for specific product (optional)
5. User clicks on product card
6. User views product details

## 2. Add to Cart Flow
1. User is on product detail page
2. User selects quantity
3. User clicks "Add to Cart"
4. Toast notification shows "Added to cart"
5. Cart icon badge updates (item count)

## 3. Checkout Flow
1. User clicks cart icon
2. User reviews cart items
3. User updates quantities (optional)
4. User clicks "Proceed to Checkout"
5. System checks authentication:
   - If not logged in → Redirect to login
   - If logged in → Continue
6. User fills shipping address
7. User selects payment method
8. User reviews order summary
9. User clicks "Place Order"
10. System processes order
11. Success → Redirect to order confirmation
12. Error → Show error message

## 4. Authentication Flow
1. User clicks "Login" or "Register"
2. **Login Path**:
   - Enter email + password
   - Submit
   - Success → Redirect to previous page
   - Error → Show error
3. **Register Path**:
   - Enter email + password + name
   - Submit
   - Success → Auto login + redirect
   - Error → Show validation errors
```
