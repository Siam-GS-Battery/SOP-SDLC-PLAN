# 4.1 Project Initialization

## วัตถุประสงค์

ตั้งค่าโปรเจกต์ให้พร้อมพัฒนา: สร้าง repository, ติดตั้ง dependencies, ตั้งค่า environment

---

## 1. สร้าง GitHub Repository

```bash
# สร้าง repo บน GitHub แล้ว clone
git clone https://github.com/username/DM-S-09-project-name.git
cd project-name

# สร้าง develop branch
git checkout -b develop
git push -u origin develop
```

**Branch Strategy:**

| Branch | หน้าที่ |
|--------|---------|
| `main` | Production (protected, ห้าม push ตรง) |
| `develop` | Development |
| `feature/*` | ฟีเจอร์ใหม่ |
| `bugfix/*` | แก้ bug |
| `hotfix/*` | แก้ไขเร่งด่วน |

## 3. Frontend Setup (Vite + React + TypeScript + Tailwind)

```bash
# สร้างโปรเจกต์ด้วย Vite
npm create vite@latest frontend -- --template react-ts
cd frontend
```

### ติดตั้ง Dependencies

```bash
# Core
npm install react-router-dom zustand axios
npm install react-hook-form zod @hookform/resolvers
npm install clsx react-icons date-fns

# Tailwind CSS
npm install -D tailwindcss @tailwindcss/vite

# Dev tools
npm install -D @types/node
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D eslint-plugin-react eslint-plugin-react-hooks eslint-config-prettier
npm install -D prettier
```

### ตั้งค่า Tailwind CSS

**`vite.config.ts`:**
```typescript
import tailwindcss from '@tailwindcss/vite'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
    react(),
  ],
})
```

**`src/index.css`:**
```css
@import "tailwindcss";
```

### เพิ่ม Scripts ใน `package.json`

```json
{
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "preview": "vite preview",
    "lint": "eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0",
    "lint:fix": "eslint . --ext ts,tsx --fix",
    "format": "prettier --write \"src/**/*.{ts,tsx,css}\""
  }
}
```

### ทดสอบ

```bash
npm run dev
# เปิด http://localhost:5173
```

## 4. Backend Setup (Node.js + TypeScript + Express)

```bash
cd ../backend
npm init -y
```

### ติดตั้ง Dependencies

```bash
# Core
npm install express cors dotenv
npm install @supabase/supabase-js pg
npm install jsonwebtoken bcrypt zod

# Dev tools
npm install -D typescript ts-node nodemon
npm install -D @types/node @types/express @types/cors @types/jsonwebtoken @types/bcrypt
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D eslint-config-prettier prettier
```

### ตั้งค่า TypeScript

```bash
npx tsc --init
```

**แก้ไข `tsconfig.json`:**
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "lib": ["ES2020"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

### สร้าง Entry Point

**`src/server.ts`:**
```typescript
import express from 'express';
import cors from 'cors';
import dotenv from 'dotenv';

dotenv.config();

const app = express();
const PORT = process.env.PORT || 5000;

app.use(cors({
  origin: process.env.ALLOWED_ORIGINS?.split(',') || 'http://localhost:5173',
  credentials: true,
}));
app.use(express.json());

app.get('/health', (req, res) => {
  res.json({ status: 'OK' });
});

app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
```

### เพิ่ม Scripts ใน `package.json`

```json
{
  "scripts": {
    "dev": "nodemon src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js",
    "lint": "eslint . --ext .ts",
    "lint:fix": "eslint . --ext .ts --fix",
    "format": "prettier --write \"src/**/*.ts\""
  }
}
```

### ทดสอบ

```bash
npm run dev
curl http://localhost:5000/health
```

## 5. Environment Variables

**สร้าง `.env.example` ที่ root:**

```bash
# Frontend
VITE_API_URL=http://localhost:5000
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key

# Backend
PORT=5000
NODE_ENV=development
DATABASE_URL=postgresql://user:password@localhost:5432/dbname
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_SERVICE_KEY=your_service_key
JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d
ALLOWED_ORIGINS=http://localhost:5173
```

> **สำคัญ:** Copy `.env.example` เป็น `.env` แล้วใส่ค่าจริง — ห้าม commit `.env`

## 6. Git Hooks (Husky)

```bash
cd ..  # กลับ root
npm init -y
npm install -D husky lint-staged
npx husky install
npm pkg set scripts.prepare="husky install"
npx husky add .husky/pre-commit "npx lint-staged"
```

**เพิ่มใน root `package.json`:**
```json
{
  "lint-staged": {
    "frontend/src/**/*.{ts,tsx}": ["cd frontend && npm run lint:fix", "cd frontend && npm run format"],
    "backend/src/**/*.ts": ["cd backend && npm run lint:fix", "cd backend && npm run format"]
  }
}
```
