### 4. สร้าง Repository Layer

> **หมายเหตุ:** Repository จัดการ database queries และ transform ข้อมูลจาก snake_case → camelCase

**ไฟล์ `src/repositories/productRepository.ts`:**

```typescript
import { pool } from '../config/database';
import { ProductDB, Product } from '../types/models';
import { transformProduct } from '../utils/transformers';

export class ProductRepository {
  async findAll(): Promise<Product[]> {
    const result = await pool.query<ProductDB>(
      'SELECT * FROM products WHERE is_active = true ORDER BY created_at DESC'
    );
    return result.rows.map(transformProduct);
  }

  async findById(id: number): Promise<Product | null> {
    const result = await pool.query<ProductDB>(
      'SELECT * FROM products WHERE id = $1',
      [id]
    );
    return result.rows[0] ? transformProduct(result.rows[0]) : null;
  }

  async findByCategory(categoryId: number): Promise<Product[]> {
    const result = await pool.query<ProductDB>(
      'SELECT * FROM products WHERE category_id = $1 AND is_active = true',
      [categoryId]
    );
    return result.rows.map(transformProduct);
  }

  async search(query: string): Promise<Product[]> {
    const result = await pool.query<ProductDB>(
      'SELECT * FROM products WHERE name ILIKE $1 OR description ILIKE $1',
      [`%${query}%`]
    );
    return result.rows.map(transformProduct);
  }

  async create(data: Partial<Product>): Promise<Product> {
    const result = await pool.query<ProductDB>(
      `INSERT INTO products (name, slug, description, price, stock_quantity, category_id, image_url, sku)
       VALUES ($1, $2, $3, $4, $5, $6, $7, $8) RETURNING *`,
      [data.name, data.slug, data.description, data.price, data.stock, data.categoryId, data.imageUrl, data.sku]
    );
    return transformProduct(result.rows[0]);
  }

  async update(id: number, data: Partial<Product>): Promise<Product | null> {
    const result = await pool.query<ProductDB>(
      `UPDATE products
       SET name = $1, price = $2, stock_quantity = $3, description = $4
       WHERE id = $5 RETURNING *`,
      [data.name, data.price, data.stock, data.description, id]
    );
    return result.rows[0] ? transformProduct(result.rows[0]) : null;
  }

  async delete(id: number): Promise<boolean> {
    const result = await pool.query('DELETE FROM products WHERE id = $1', [id]);
    return result.rowCount ? result.rowCount > 0 : false;
  }
}

export const productRepository = new ProductRepository();
```

### 5. สร้าง Service Layer

**ไฟล์ `src/services/productService.ts`:**

```typescript
import { productRepository } from '../repositories/productRepository';
import { Product } from '../types/models';

export class ProductService {
  async getAllProducts(): Promise<Product[]> {
    return productRepository.findAll();
  }

  async getProductById(id: number): Promise<Product | null> {
    return productRepository.findById(id);
  }

  async createProduct(data: Partial<Product>): Promise<Product> {
    // Business logic: Generate slug
    const slug = data.name!.toLowerCase().replace(/\s+/g, '-');

    return productRepository.create({ ...data, slug });
  }

  async updateProduct(id: number, data: Partial<Product>): Promise<Product | null> {
    const product = await productRepository.findById(id);
    if (!product) {
      throw new Error('Product not found');
    }

    return productRepository.update(id, data);
  }

  async deleteProduct(id: number): Promise<boolean> {
    return productRepository.delete(id);
  }
}

export const productService = new ProductService();
```

### 6. สร้าง Controller Layer

**ไฟล์ `src/controllers/productController.ts`:**

```typescript
import { Request, Response, NextFunction } from 'express';
import { productService } from '../services/productService';

export class ProductController {
  async getAll(req: Request, res: Response, next: NextFunction) {
    try {
      const products = await productService.getAllProducts();
      res.json({ success: true, data: products });
    } catch (error) {
      next(error);
    }
  }

  async getById(req: Request, res: Response, next: NextFunction) {
    try {
      const { id } = req.params;
      const product = await productService.getProductById(Number(id));

      if (!product) {
        return res.status(404).json({ success: false, message: 'Product not found' });
      }

      res.json({ success: true, data: product });
    } catch (error) {
      next(error);
    }
  }

  async create(req: Request, res: Response, next: NextFunction) {
    try {
      const product = await productService.createProduct(req.body);
      res.status(201).json({ success: true, data: product });
    } catch (error) {
      next(error);
    }
  }

  async update(req: Request, res: Response, next: NextFunction) {
    try {
      const { id } = req.params;
      const product = await productService.updateProduct(Number(id), req.body);

      if (!product) {
        return res.status(404).json({ success: false, message: 'Product not found' });
      }

      res.json({ success: true, data: product });
    } catch (error) {
      next(error);
    }
  }

  async delete(req: Request, res: Response, next: NextFunction) {
    try {
      const { id } = req.params;
      const deleted = await productService.deleteProduct(Number(id));

      if (!deleted) {
        return res.status(404).json({ success: false, message: 'Product not found' });
      }

      res.json({ success: true, message: 'Product deleted' });
    } catch (error) {
      next(error);
    }
  }
}

export const productController = new ProductController();
```

### 8. สร้าง Error Handler Middleware

**ไฟล์ `src/middlewares/errorHandler.ts`:**

```typescript
import { Request, Response, NextFunction } from 'express';

export class AppError extends Error {
  constructor(
    public statusCode: number,
    public message: string,
    public isOperational = true
  ) {
    super(message);
    Object.setPrototypeOf(this, AppError.prototype);
  }
}

export function errorHandler(
  err: Error | AppError,
  req: Request,
  res: Response,
  next: NextFunction
) {
  if (err instanceof AppError) {
    return res.status(err.statusCode).json({
      success: false,
      message: err.message,
    });
  }

  console.error('ERROR:', err);
  return res.status(500).json({
    success: false,
    message: 'Internal server error',
  });
}
```

});

### ✅ สิ่งที่สอดคล้องแล้ว:

1. **Data Models** — ใช้ types จาก 5.3 Frontend Analyze (แยกเป็น DB models และ API models)
2. **Database Connection** — เชื่อมต่อ Supabase ที่ setup ใน 5.5 Database Design
3. **Mock Data** — ใช้ข้อมูลที่ migrate ไว้แล้วจาก 5.4 + 5.5
4. **Field Transformation** — มี transformer layer แปลง snake_case ↔ camelCase

### ⚠️ สิ่งที่ยังขาดและควรเพิ่ม:

#### 1. **API Endpoints ยังไม่ครบตาม 5.3**

**ปัจจุบันมี:**
- ✅ Products API (GET, POST, PUT, DELETE)
- ✅ Categories API (GET)

**ยังขาด:**
- ❌ Auth API (login, register, logout, me)
- ❌ Cart API (get cart, add to cart, update, remove)
- ❌ Orders API (get orders, create order, get order by id)
- ❌ User Profile API (get profile, update profile)
- ❌ Reviews API (get reviews, create review)

#### 2. **Authentication & Authorization ยังไม่มี**

ตาม 5.3 มี Protected Routes และ Admin Routes แต่ Backend ยังไม่มี:
- ❌ JWT authentication middleware
- ❌ Authorization middleware (role checking)
- ❌ Password hashing (bcrypt)
- ❌ Login/Register endpoints

#### 3. **Validation ยังไม่มี**

- ❌ Request body validation (Zod, Joi, หรือ express-validator)
- ❌ Input sanitization

### 📝 แนวทางแก้ไข:

**Option 1:** สร้าง section ใหม่ **"5.7 Complete Backend APIs"** เพื่อเพิ่ม:
- Auth endpoints + JWT middleware
- Cart endpoints
- Orders endpoints
- Reviews endpoints
- Validation middleware

**Option 2:** ขยายไฟล์นี้ (5.6) ให้ครอบคลุมทุก endpoints ทันที

**แนะนำ:** ใช้ Option 1 เพราะแยก concerns ชัดเจนกว่า
