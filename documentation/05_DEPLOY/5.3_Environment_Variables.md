# 5.3 Environment Variables — ตัวแปรสภาพแวดล้อม

## วัตถุประสงค์

เอกสารนี้รวบรวม Environment Variables ทั้งหมดที่ต้องตั้งค่าสำหรับ Backend และ Frontend พร้อมคำอธิบายและตัวอย่าง

---

## 1. Backend Environment Variables

### 1.1 ตารางตัวแปรทั้งหมด

| Variable | ค่าตัวอย่าง | คำอธิบาย | ความสำคัญ |
|----------|------------|----------|-----------|
| `PORT` | `5001` | Port ที่ Backend ใช้งาน | **จำเป็น** |
| `NODE_ENV` | `production` | Environment mode | **จำเป็น** |
| `SUPABASE_URL` | `https://xxxxx.supabase.co` | URL ของ Supabase project | **จำเป็น** |
| `SUPABASE_ANON_KEY` | `eyJhbGciOiJIUzI1NiIs...` | Public API key สำหรับ client | **จำเป็น** |
| `SUPABASE_SERVICE_KEY` | `eyJhbGciOiJIUzI1NiIs...` | Service role key สำหรับ admin | **จำเป็น** |
| `JWT_SECRET` | `K7gNU3sdo+OL0wNhqoV...` | Secret key สำหรับ JWT signing | **จำเป็น** |
| `JWT_EXPIRES_IN` | `2h` | อายุของ JWT token | แนะนำ |
| `FRONTEND_URL` | `https://xxx.up.railway.app` | URL ของ Frontend สำหรับ CORS | **จำเป็น** |
| `SESSION_DURATION` | `1800000` | ระยะเวลา session (30 นาที) | ทางเลือก |
| `SESSION_WARNING_TIME` | `300000` | เวลาแจ้งเตือนก่อน session หมด | ทางเลือก |
| `SESSION_MAX_EXTENSIONS` | `3` | จำนวนครั้งที่ต่อ session ได้ | ทางเลือก |
| `MAX_FILE_SIZE` | `5242880` | ขนาดไฟล์สูงสุด (5MB) | ทางเลือก |
| `ALLOWED_FILE_TYPES` | `image/jpeg,image/png,...` | ประเภทไฟล์ที่อนุญาต | ทางเลือก |
| `RATE_LIMIT_WINDOW_MS` | `900000` | ช่วงเวลา rate limit (15 นาที) | ทางเลือก |
| `RATE_LIMIT_MAX_REQUESTS` | `100` | จำนวน requests สูงสุดต่อช่วงเวลา | ทางเลือก |

### 1.2 คำอธิบายแต่ละตัวแปร

#### ตัวแปรพื้นฐาน

```env
# Port ที่ Backend รับ connections
# Railway จะใช้ port นี้ในการ route traffic
PORT=5001

# บอก Node.js ว่าอยู่ใน production mode
# จะปิด debug logs และเปิด optimizations
NODE_ENV=production
```

#### ตัวแปร Supabase

```env
# URL ของ Supabase project
# รูปแบบ: https://<project-id>.supabase.co
SUPABASE_URL=https://nmdklroldxfdodnvfbls.supabase.co

# Public API key - ใช้สำหรับ client-side operations
# มีสิทธิ์จำกัดตาม Row Level Security (RLS)
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Service role key - มีสิทธิ์เต็มที่ (bypass RLS)
# ⚠️ ใช้เฉพาะ server-side เท่านั้น!
SUPABASE_SERVICE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

#### ตัวแปร JWT

```env
# Secret key สำหรับ sign JWT tokens
# ต้องเป็นค่าที่ซับซ้อนและเก็บเป็นความลับ
JWT_SECRET=K7gNU3sdo+OL0wNhqoVWhr3g6s1xYv72ol/pe/Unols=

# อายุของ JWT token
# รูปแบบ: 1h, 2h, 1d, 7d
JWT_EXPIRES_IN=2h
```

#### ตัวแปร CORS

```env
# URL ของ Frontend ที่อนุญาตให้เรียก API
# ใช้สำหรับ CORS configuration
# ⚠️ ต้องไม่มี / ต่อท้าย!
FRONTEND_URL=https://your-frontend.up.railway.app
```

#### ตัวแปร Session

```env
# ระยะเวลา session (milliseconds)
# 1800000 = 30 นาที
SESSION_DURATION=1800000

# เวลาแจ้งเตือนก่อน session หมด
# 300000 = 5 นาที
SESSION_WARNING_TIME=300000

# จำนวนครั้งที่ผู้ใช้สามารถต่ออายุ session ได้
SESSION_MAX_EXTENSIONS=3
```

#### ตัวแปร File Upload

```env
# ขนาดไฟล์สูงสุดที่อนุญาต (bytes)
# 5242880 = 5MB
MAX_FILE_SIZE=5242880

# ประเภทไฟล์ที่อนุญาต (MIME types)
# คั่นด้วย comma
ALLOWED_FILE_TYPES=image/jpeg,image/png,image/gif,application/pdf
```

#### ตัวแปร Rate Limiting

```env
# ช่วงเวลาสำหรับ rate limiting (milliseconds)
# 900000 = 15 นาที
RATE_LIMIT_WINDOW_MS=900000

# จำนวน requests สูงสุดต่อ IP ในช่วงเวลาที่กำหนด
RATE_LIMIT_MAX_REQUESTS=100
```

## 2. Frontend Environment Variables

### 2.1 ตารางตัวแปรทั้งหมด

| Variable | ค่าตัวอย่าง | คำอธิบาย | ความสำคัญ |
|----------|------------|----------|-----------|
| `REACT_APP_API_BASE_URL` | `https://xxx.up.railway.app/api` | URL ของ Backend API | **จำเป็น** |
| `REACT_APP_WEBSOCKET_URL` | `https://xxx.up.railway.app` | URL สำหรับ WebSocket | **จำเป็น** |
| `REACT_APP_NODE_ENV` | `production` | Environment mode | แนะนำ |
| `DISABLE_ESLINT_PLUGIN` | `true` | ปิด ESLint ตอน build | แนะนำ |

### 2.2 คำอธิบายแต่ละตัวแปร

```env
# URL ของ Backend API
# ⚠️ ต้องมี /api ต่อท้าย!
REACT_APP_API_BASE_URL=https://your-backend.up.railway.app/api

# URL สำหรับ WebSocket connection
# ⚠️ ต้องใช้ https:// (ไม่ใช่ wss://)
# ⚠️ ไม่มี path ต่อท้าย!
REACT_APP_WEBSOCKET_URL=https://your-backend.up.railway.app

# Environment mode
REACT_APP_NODE_ENV=production

# ปิด ESLint ตอน build เพื่อป้องกัน build failed
# จาก warnings ที่ไม่สำคัญ
DISABLE_ESLINT_PLUGIN=true
```

### 2.3 ตัวอย่าง Frontend Environment (ทั้งหมด)

```env
REACT_APP_API_BASE_URL=https://your-backend.up.railway.app/api
REACT_APP_WEBSOCKET_URL=https://your-backend.up.railway.app
REACT_APP_NODE_ENV=production
DISABLE_ESLINT_PLUGIN=true
```

## 3. ข้อควรระวังสำคัญ

### 3.1 ความปลอดภัย

| ⚠️ ข้อควรระวัง | คำอธิบาย |
|---------------|----------|
| **อย่า commit keys ลง GitHub** | ใช้ `.gitignore` ป้องกันไฟล์ `.env` |
| **Service Key เป็นความลับ** | `SUPABASE_SERVICE_KEY` ห้ามเปิดเผย |
| **JWT Secret ต้องไม่ซ้ำ** | ใช้ค่าที่แตกต่างกันใน Production และ Development |
| **ไม่ใช้ค่าตัวอย่างจริง** | เปลี่ยนค่าทั้งหมดก่อน Deploy |

### 3.2 รูปแบบ URL ที่ถูกต้อง

```env
# ❌ ผิด - มี / ต่อท้าย
FRONTEND_URL=https://your-frontend.up.railway.app/

# ✅ ถูก - ไม่มี / ต่อท้าย
FRONTEND_URL=https://your-frontend.up.railway.app
```

```env
# ❌ ผิด - ไม่มี /api
REACT_APP_API_BASE_URL=https://your-backend.up.railway.app

# ✅ ถูก - มี /api
REACT_APP_API_BASE_URL=https://your-backend.up.railway.app/api
```

### 3.3 Frontend Variables ต้องขึ้นต้นด้วย REACT_APP_

```env
# ❌ ผิด - Frontend จะไม่เห็นตัวแปรนี้
API_URL=https://...

# ✅ ถูก - Frontend จะเห็นตัวแปรนี้
REACT_APP_API_URL=https://...
```

## 4. วิธีตั้งค่าบน Railway

### 4.1 ผ่าน Dashboard (แนะนำ)

1. ไปที่ Service ที่ต้องการ
2. คลิกแท็บ **"Variables"**
3. คลิก **"New Variable"**
4. กรอก Key และ Value
5. คลิก **"Add"**

### 4.2 ผ่าน Raw Editor (เร็วกว่า)

1. ไปที่ Service → **"Variables"**
2. คลิก **"Raw Editor"**
3. Paste ตัวแปรทั้งหมด:
   ```
   PORT=5001
   NODE_ENV=production
   SUPABASE_URL=https://...
   ...
   ```
4. คลิก **"Update Variables"**

> **💡 Tip:** ใช้ Raw Editor เมื่อต้องเพิ่มหลายตัวแปรพร้อมกัน

### 4.3 ลำดับการตั้งค่า

```
1. Deploy Backend ก่อน → ได้ Backend URL
2. ตั้งค่า Frontend Variables → ใส่ Backend URL
3. Deploy Frontend → ได้ Frontend URL
4. กลับไปอัปเดต Backend → ใส่ FRONTEND_URL
```

## 5. Checklist Environment Variables

### Backend

- [ ] `PORT` = `5001`
- [ ] `NODE_ENV` = `production`
- [ ] `SUPABASE_URL` = URL ของ Supabase
- [ ] `SUPABASE_ANON_KEY` = Anon key จาก Supabase
- [ ] `SUPABASE_SERVICE_KEY` = Service key จาก Supabase
- [ ] `JWT_SECRET` = สร้างค่าใหม่ (ไม่ใช้ค่าตัวอย่าง)
- [ ] `JWT_EXPIRES_IN` = `2h`
- [ ] `FRONTEND_URL` = URL ของ Frontend (อัปเดตหลัง deploy frontend)

### Frontend

- [ ] `REACT_APP_API_BASE_URL` = URL ของ Backend + `/api`
- [ ] `REACT_APP_WEBSOCKET_URL` = URL ของ Backend
- [ ] `REACT_APP_NODE_ENV` = `production`
- [ ] `DISABLE_ESLINT_PLUGIN` = `true`
