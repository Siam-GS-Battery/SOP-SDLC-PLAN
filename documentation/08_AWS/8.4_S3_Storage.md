# 8.4 S3 Storage

S3 ใช้สำหรับเก็บไฟล์ที่ผู้ใช้อัปโหลด (รูปภาพ, เอกสาร) ในสถาปัตยกรรม KAIZEN ใช้ 2 buckets สำหรับ Blue-Green deployment

---

## 4.1 สร้าง Buckets

ไปที่ **S3 Dashboard** → คลิก **"Create bucket"** สร้าง 2 buckets:

| ชื่อ Bucket | วัตถุประสงค์ |
|:-----------|:-----------|
| `p-[ชื่อโปรเจค]-s3-bucket-blue` | Blue environment (staging/testing) |
| `p-[ชื่อโปรเจค]-s3-bucket-prd` | Production environment |

> **ชื่อ S3 Bucket ต้องไม่ซ้ำกันทั่วโลก** — ควรใส่ชื่อบริษัทหรือโปรเจคนำหน้าเพื่อลดโอกาสซ้ำ

---

## 4.2 ตั้งค่า Bucket

| การตั้งค่า | ค่า | เหตุผล |
|:----------|:----|:------|
| **Region** | เลือก Region เดียวกับ EC2 และ RDS | ลด latency |
| **Block Public Access** | เปิดทั้งหมด (Block all) | เข้าถึงผ่าน CloudFront แทน |
| **Versioning** | เปิด | ป้องกันลบไฟล์โดยไม่ตั้งใจ |
| **Encryption** | เปิด Server-side encryption (AWS KMS) | ความปลอดภัย |

---

## 4.3 ตั้งค่า Bucket Policy

เพิ่ม policy ให้ CloudFront เข้าถึง S3 ได้ (แก้ `[ACCOUNT-ID]` และ `[DISTRIBUTION-ID]` เป็นของจริง):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowCloudFrontAccess",
      "Effect": "Allow",
      "Principal": {
        "Service": "cloudfront.amazonaws.com"
      },
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::p-[ชื่อโปรเจค]-s3-bucket-prd/*",
      "Condition": {
        "StringEquals": {
          "AWS:SourceArn": "arn:aws:cloudfront::[ACCOUNT-ID]:distribution/[DISTRIBUTION-ID]"
        }
      }
    }
  ]
}
```
