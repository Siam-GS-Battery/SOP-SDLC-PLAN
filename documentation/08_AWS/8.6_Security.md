# 8.6 Security

ตั้งค่าความปลอดภัยสำหรับ AWS resources ทั้งหมด

---

## 6.1 AWS Secrets Manager

ใช้เก็บข้อมูลลับ (database password, API keys) แทนการ hardcode ใน source code

1. ไปที่ **Secrets Manager** → คลิก **"Store a new secret"**
2. เลือก **"Credentials for Amazon RDS database"**
3. ใส่ username/password ของ RDS แล้วเลือก RDS instance
4. ตั้งชื่อ secret เช่น `p-[ชื่อโปรเจค]/db-credentials`

---

## 6.2 AWS KMS (Key Management Service)

KMS ใช้สำหรับจัดการ encryption keys:

| สร้าง KMS Key สำหรับ | กำหนดสิทธิ์ |
|:--------------------|:-----------|
| S3 encryption | เฉพาะ IAM roles ที่จำเป็น |
| RDS encryption | เฉพาะ IAM roles ที่จำเป็น |

---

## 6.3 SSL/TLS Certificate

ขอ SSL certificate ฟรีจาก **AWS Certificate Manager (ACM)**:

1. ไปที่ **ACM** → คลิก **"Request a certificate"**
2. เลือก **"Request a public certificate"**
3. ใส่โดเมนเนม: `yourdomain.co.th` และ `*.yourdomain.co.th`
4. เลือก **DNS validation** แล้วเพิ่ม CNAME record ตามที่ ACM แนะนำ

> **สำหรับ CloudFront ต้องขอ certificate ที่ us-east-1 (N. Virginia) เท่านั้น**
> แม้ว่า resources อื่นจะอยู่ที่ region อื่น ต้องสลับไปที่ us-east-1 ก่อนขอ certificate

---

## 6.4 ตั้งค่า Monitoring

| Service | วัตถุประสงค์ | สิ่งที่ต้องทำ |
|:--------|:-----------|:------------|
| **CloudWatch** | Monitoring | ตั้ง dashboards สำหรับ EC2 CPU, Memory, RDS connections + ตั้ง Alarms |
| **CloudTrail** | Audit logging | เปิดใช้งานเพื่อบันทึกทุก API call (สำหรับ audit) |
| **Cost Explorer** | ค่าใช้จ่าย | เปิดใช้งาน + ตั้ง Budget Alerts เมื่อเกินงบ |
